- **같은 조건** — 업무 규칙 `docs/business-rule.md`, 수용 테스트 `test/AmountTest.java`, 실행 `sh run-tests.sh`

- LLM 시간은 CLI가 보고한 `duration_ms`의 합이다. 사람이 붙여 넣고 테스트를 돌린 시간은 포함하지 않는다.
- 입력 토큰에는 도구의 시스템 프롬프트와 도구 정의가 포함된다. 호출할 때마다 다시 들어가므로 호출·턴이 많을수록 커진다.
- 파일: `*-prompt*.txt`(프롬프트), `*.diff`(바뀐 코드), `chat-test*.txt`(대화형 보조의 테스트 출력), `results.json`(CLI 출력 전체).
- 같은 시연을 다시 하면 결과는 달라질 수 있다(비결정성). 수치는 이 실행 한 번의 기록이다.
