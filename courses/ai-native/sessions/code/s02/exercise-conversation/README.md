# 실습 2 — 실제 대화와 최종 요구사항

- `templates.json`은 수강생용 기본 문구, `prompt-*`와 `codex-response-*`는 실제 입력·응답이다.
- `conversation.md`에 전체 대화를 보존한다. 대화 횟수는 예시이며 수강생의 보완 횟수를 제한하지 않는다.
- `정기배송-최초신청-요구사항.md`는 `codex-response-05.md`와 동일한 최종 파일이며 실습 3의 입력이다.
- `input-s01.md`는 이 예시를 처음 실행했을 때 첨부한 업무 조건의 스냅샷이다. 실제 과거 입력을 현재 파일로 덮어쓰지 않는다.
- `exercise-conditions.md`와 업무·품질 조건 자료는 예시의 결정 근거다. 품질 수치는 교육용 가정이다.
- 실행 입력·이벤트·메타데이터와 CLI 실행기를 보존한다. 최종 파일을 검토한 뒤 필요하면 재생성한다.

교재 원천은 `sessions/s02.md`다. 통합 전 검토본과 과거 실패 백업은 로컬 정리 백업으로 옮겼다. 상세 위치는 저장소의 `REPOSITORY-STATUS.md`를 본다.
