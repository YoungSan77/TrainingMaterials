[이전 MD 검토]
구성·값·도식·미정 판단은 그대로 간다. 두 표가 표로 읽히지 않는다.

1. 「규칙의 대표 예」를 표 하나에 몰아넣어 칸마다 문장이 들어갔다. 행을 훑어 비교할 수 없고 한 칸을 다 읽어야 뜻이 잡힌다. 표를 버리고 네 예를 각각 짧은 목록으로 적어라. 예마다 전제·사건·결과·유지되는 값을 한 줄씩 두고, 각 줄은 한 호흡에 읽히는 짧은 구로 끊어라.
2. 「전이 목록」은 표로 두되 현재 상태·사건·다음 상태·범위 네 열로 줄여라. 반응은 표 아래 목록에 사건별로 적어라. 상태 칸에는 한글 이름만 쓰고 코드 값은 표 아래 한 줄로 모아라.
3. 두 곳 모두 표의 칸에 문장을 넣지 말고 짧은 말로 끊어라.

[최종 파일 생성]
위를 고쳐 같은 동적 관점 문서를 다시 생성해라.

- 구성은 도입, 상태 기계, 전이 목록, 정상 승인 시퀀스, 규칙의 대표 예, 금지·참고 조건·미정·범위 밖이다.
- 상태 기계와 시퀀스는 Mermaid 원본을 그대로 보존한다. 금지 목록과 미정 목록의 문장도 보존한다.
- 네 예의 값(주문 A·펜 2개·확정 단가 1,000원·총액 2,000원·배송지 서울·배송 요청 횟수)과 전이 목록의 상태·사건·범위를 하나도 빼지 마라.
- 요구사항 정의서와 정적 관점을 다시 설명하지 않는다. 새 정책·새 상태·새 전이를 추가하지 마라. 미정은 미정으로 적는다.
- 대화 과정을 설명하는 절은 넣지 않는다.
