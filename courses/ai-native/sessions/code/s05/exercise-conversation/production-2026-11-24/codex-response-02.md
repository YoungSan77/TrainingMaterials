반영할 합의는 다음과 같습니다.

- 상태 기계에는 정확히 세 전이만 둡니다.
  1. `배송지 지정`: 주문 생성과 `PENDING_PAYMENT` 최초 진입
  2. `카드 승인 거절`: `PENDING_PAYMENT` 자기 전이
  3. `카드 승인 완료`: `PENDING_PAYMENT`에서 `PAID`로 전이
- 생성 전은 주문 상태로 표현하지 않습니다.
- 재결제 요청과 배송 성공·실패는 상태 전이에서 제외합니다.
- 상태 기계와 전이 목록에는 위 사건 이름을 동일하게 사용합니다.
- 배송은 승인 완료와 `PAID` 전환 뒤 확정 배송지 서울로 요청하며, 거절 시에는 0회입니다.
- 시퀀스 다이어그램은 고객·주문 시스템·결제 시스템·배송 시스템이 참여하는 정상 승인 장면 하나만 제시합니다.
- 상태 변경은 시퀀스의 메시지가 아닌 주석으로 표시합니다.
- 주문 결과 확인과 배송 요청의 세부 순서, 별도 통지 여부, 동기·비동기 방식은 확정하지 않습니다.
- 조회·변경 상호작용 상세는 생략합니다.
- 네 대표 사례를 짧게 구분합니다: 정상 승인, 판매가 1,200원 변경 후 승인, 카드 X 거절, 같은 주문에서 카드 Y 재결제.
- 모든 사례에서 펜 2개, 기록 단가 1,000원, 확정 총액 2,000원을 기준으로 하며, 재결제에서도 같은 주문 식별과 2,000원을 유지합니다.
- 미확정 승인 응답과 배송 요청 실패의 후속 정책은 결정하지 않고 질문으로 남깁니다.
