확정 입력 두 문서와 대조했다. 카드 승인 거절은 결제대기 자기 전이지만, 다른 카드로 재결제를 요청하는 행위는 별도의 상태 전이로 추가하지 마라. 주문 생성 전은 상태가 아니며, 결제완료에서 종료점으로 연결하거나 배송 성공을 상태 전이로 넣지 마라. 시퀀스는 고객·주문 시스템·결제 시스템·배송 시스템의 정상 승인 장면 하나로 한정하고, 카드 승인 완료 뒤 결제완료 상태에서 서울로 배송을 요청하는 선후를 보여라. 고객의 결과 확인은 포함할 수 있지만 별도 통지와 배송 요청과의 세부 선후는 정하지 마라. 같은 주문의 카드 X 거절과 카드 Y 재결제는 전이 목록·대표 사례에 둬라. 확정 단가 1,000원·펜 2개·총액 2,000원과 판매가 1,200원 사례를 유지하라. 미확정 응답과 배송 요청 실패의 후속 처리는 질문으로 남겨라. 검토 가능한 수정안을 보여라.
