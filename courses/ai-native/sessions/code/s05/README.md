# 작업 명세와 수용 기준 실행 예

저장소 루트에서 JDK 17 이상과 Node.js로 실행한다.

```sh
node courses/ai-native/sessions/code/s05/run.mjs
```

실행기는 임시 폴더에 AcceptanceExamples.java를 컴파일하고 승인·가격 변경·거절·재결제 네 예를 실행한다. 모든 검사 통과와 네 PASS 출력을 확인한 뒤 features.json을 작성한다. 실행기는 자신이 만든 임시 컴파일 폴더만 제거한다. 외부 라이브러리나 실제 결제·배송 호출은 없다.

예의 기대값은 과정 공통 규칙이다. 펜 2개·단가 1,000원·총액 2,000원·배송지 서울을 사용한다. 판매가 변경 뒤 확정 단가와 승인 요청 금액을 확인하고, 배송 요청 때 결제완료인지 검사한다. 거절 뒤 다른 카드로 같은 Order 인스턴스를 재결제한다. 사용자 정의 equal은 불일치 시 AssertionError를 던진다.

현재 예는 계산과 결제 흐름의 수용 예다. 식별·영속·동시성·운영용 입력 검증·실제 API 연동은 생략했다. 승인 뒤 배송 요청 실패, 통신 오류, 중복 승인 처리 정책은 구현하거나 테스트 기대값으로 정하지 않았다. 구조 검사는 세션 04의 별도 예이며 이 실행기가 수행하지 않는다.

원고의 Given–When–Then은 같은 예를 설명하는 명세다. Cucumber 실행 환경을 설치하지 않고 Java 테스트로 실행한다.

시연은 2026-10-08의 실제 저장 기록 `../s04/demo-results/`를 참조한다. 새로 실행한 결과로 소개하지 않는다. 현재 수용 예의 PASS와 과거 시연 결과를 구분한다.
