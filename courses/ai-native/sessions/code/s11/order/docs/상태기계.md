# 주문의 상태와 전이

## 상태

| 상태 | 뜻 | 코드 값 |
| --- | --- | --- |
| 결제대기 | 주문이 생겼고 아직 결제되지 않았다 | `PENDING_PAYMENT` |
| 결제완료 | 결제가 승인되었다 | `PAID` |
| 배송중 | 배송이 시작되었다 | `IN_DELIVERY` |
| 배송완료 | 배송이 끝났다 | `DELIVERED` |

취소됨 상태는 **두지 않는다.** 취소는 이번 과제의 범위 밖이다.

## 허용된 전이

| 사건 | 전 | 후 |
| --- | --- | --- |
| 주문이 생긴다 | — | 결제대기 |
| 결제가 승인된다 | 결제대기 | 결제완료 |
| 결제가 거절된다 | 결제대기 | 결제대기 (자기 전이) |
| 배송이 시작된다 | 결제완료 | 배송중 |
| 배송이 끝난다 | 배송중 | 배송완료 |

## 금지된 순서

- 결제완료가 되기 **전에** 배송을 요청하지 않는다.
- 배송중·배송완료에서 다시 결제하지 않는다.

## 정하지 않은 전이

- 결제완료에서 **배송 요청이 실패**했을 때의 전이는 없다. 만들지 않는다(`docs/업무규칙.md`).
