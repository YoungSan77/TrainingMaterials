# 의존 규칙

## 패키지

| 패키지 | 무엇이 사는가 |
| --- | --- |
| `order` | 주문·주문 항목·주문 서비스 |
| `payment` | 결제 포트와 결제 요청·결과 |
| `delivery` | 배송 포트와 배송 요청 |
| `product` | 상품 포트와 금액·상품 번호 |
| `paymentadapter`·`deliveryadapter` | 외부 시스템과 통신하는 연동 |
| `persistence` | 저장 구현 |

## 규칙

- 업무 패키지(`order`·`payment`·`delivery`·`product`)는 **연동과 영속을 import하지 않는다.**
  외부 시스템은 포트 인터페이스로만 안다. 구현을 끼우는 일은 업무 밖에서 한다.
- 업무 패키지 사이의 의존은 **허용 목록**만 쓴다 — `order->payment`, `order->delivery`, `order->product`.
- 패키지 의존에 **순환이 없다.**

`./gradlew check`의 `dependencyRules`가 이 규칙을 판정한다.
