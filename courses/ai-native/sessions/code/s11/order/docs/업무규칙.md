# 업무 규칙

업무 담당자가 정했다. 코드가 이 셋을 지켜야 한다.

1. **주문 금액** — 주문이 생길 때의 판매가로 정한다. 결제 직전에 판매가가 바뀌어도 주문 금액은 그대로다.
2. **배송 요청** — 결제가 **승인된 뒤에만** 한다. 승인 전에는 배송 시스템을 부르지 않는다.
3. **결제 거절** — 주문은 결제대기로 남고, **다른 카드로 다시 결제할 수 있다**. 거절로 주문을 정리하지 않는다.

## 아직 정하지 않은 것

- **승인 뒤 배송 요청이 실패하면 어떻게 하는가** — 주문은 이미 결제완료다. 취소할지, 다시 요청할지,
  사람에게 알릴지 **업무 담당자가 아직 정하지 않았다.** 이 경우의 기대 상태나 복구 동작을 만들지 않는다.
- **결제가 확정 불가로 돌아온 뒤의 처리** — 승인도 거절도 아닌 결과다. 역시 정하지 않았다.
