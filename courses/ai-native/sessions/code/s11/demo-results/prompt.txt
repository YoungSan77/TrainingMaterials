이 저장소의 `AGENTS.md`를 먼저 읽고, 거기서 가리키는 문서만 필요할 때 찾아 읽어라.

`docs/작업명세서.md`가 정한 **남은 작업 단위 셋(승인·거절·재결제)**을 구현해라. 수용 기준 넷이 각각
테스트로 확인되어야 하고, `./gradlew check`가 녹색이어야 끝난 것이다.

지켜야 할 것

- 문서를 고치지 마라. 기존 테스트와 `build.gradle.kts`도 고치지 마라.
- 문서가 정하지 않은 정책에 닿으면 **멈추고 물어라.** 추측으로 채우지 마라.
- 저장소 밖에 파일을 만들지 마라.

끝나면 다음을 적어 보고해라.

1. 만든 파일과 고친 파일의 목록
2. `./gradlew check`의 실제 출력
3. 문서가 정하지 않아 **멈추고 묻는 것**이 있으면 그 질문
