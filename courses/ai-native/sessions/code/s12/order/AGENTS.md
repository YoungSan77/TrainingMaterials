# 주문 시스템 — 저장소 안내

이 저장소는 쇼핑몰의 주문 시스템이다. 첫 기능 "주문한다"를 작업 단위로 나누어 만들고 있다.
**금액 확정** 단위는 끝났고, 남은 셋이 이번 작업이다.

## 먼저 읽을 것

이 파일 하나만 꼭 읽는다. 나머지는 판단에 필요할 때 찾아 읽는다.

| 문서 | 답하는 질문 |
| --- | --- |
| `docs/용어집.md` | 무엇이라고 부르는가? |
| `docs/업무규칙.md` | 무엇이 옳은 결과인가? |
| `docs/상태기계.md` | 어떤 전이가 허용되는가? |
| `docs/아키텍처.md` | 무엇을 몰라야 하는가? |
| `docs/작업명세서.md` | 이번에 무엇을 만드는가? |

## 검사

```sh
./gradlew check
```

컴파일, 수용 테스트, 의존 규칙, 결합도를 한 번에 돌린다. **검사가 녹색이어야 완료다.**

## 지켜야 할 것

- **문서를 고치지 않는다.** 문서가 정한 것과 다르게 만들어야 할 이유가 생기면 멈추고 묻는다.
- **검사와 빌드 구성을 고치지 않는다.** `build.gradle.kts`와 기존 테스트는 그대로 둔다.
- **문서가 정하지 않은 정책에 닿으면 멈추고 묻는다.** 추측으로 채우지 않는다.
- 저장소 밖에 파일을 만들지 않는다.
