# 작업 명세서 — 주문을 취소한다

## 유저 스토리

고객으로서 결제한 주문을 취소하고 싶다. 더 필요 없어진 주문에 돈을 내지 않기 위해서다.

## 업무 규칙과 예

`docs/business-rules.md`의 4·5·6번을 따른다. 대표 예는 아래와 같다.

- 펜 2개(2,000원) 주문이 **결제완료**다 → 취소하면 **취소됨**이다.
- 같은 주문이 **배송중**이다 → 취소를 요청해도 **배송중 그대로**다.
- 취소된 주문에 다시 결제를 요청한다 → **취소됨 그대로**이고 결제 시스템에 **승인을 요청하지 않는다**.

## 수용 기준

`test/CancelAcceptanceTest`의 네 테스트가 그대로 수용 기준이다. 기대값은 바꾸지 않는다.

## 범위

- `order` 패키지에 취소를 구현한다. 주문 상태 전이는 `docs/order-state.md`를 따른다.
- 배송 시작 통보를 받는 `onDeliveryStarted`가 없으면 함께 만든다(상태 기계의 결제완료 → 배송중 전이).

## 제외

- 환불과 배송 취소 통보는 이번 범위가 아니다. 결제·배송 시스템에 새 호출을 더하지 않는다.
- 취소 사유와 이력은 다루지 않는다.

## 미정

- 배송중인 주문을 고객이 취소하려 할 때 무엇을 안내할지는 업무 담당자가 아직 정하지 않았다. 코드에서 정하지 말고 질문으로 남긴다.
