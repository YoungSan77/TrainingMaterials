# 주문 상태 기계

```text
[*] → 결제대기
결제대기 → 결제대기 : 결제 거절됨
결제대기 → 결제완료 : 결제 승인됨 / 배송을 요청한다
결제완료 → 배송중   : 배송 시작 통보
배송중   → 배송완료 : 배송 완료 통보
결제완료 → 취소됨   : 주문을 취소한다
```

- 화살표가 **없는 전이는 금지**다. 배송중·배송완료·취소됨에서 취소로 가는 전이는 없다.
- 결제대기에서 결제가 거절되면 **결제대기에 머문다**. 다른 결제 수단으로 다시 결제할 수 있다.
- 취소됨은 끝 상태다. 취소된 주문은 다시 결제할 수 없다.
