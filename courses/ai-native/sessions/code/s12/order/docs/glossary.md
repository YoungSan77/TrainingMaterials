# 용어집

| 한글 | 영문 | 뜻 |
|---|---|---|
| 주문 | `Order` | 고객이 상품을 골라 배송지를 정하고 결제하는 단위 |
| 주문 항목 | `OrderItem` | 주문에 담긴 상품과 수량. 단가는 주문이 생길 때 확정한다 |
| 주문 상태 | `OrderStatus` | 결제대기·결제완료·배송중·배송완료·취소됨 |
| 판매가 | `salePrice` | 상품의 현재 가격. 언제든 바뀔 수 있다 |
| 단가 | `unitPrice` | 주문 항목이 주문 시점에 확정한 가격. 뒤에 판매가가 바뀌어도 그대로다 |
| 주문 금액 | `totalAmount` | 단가 × 수량의 합 |
| 배송지 | `shippingAddress` | 주문이 배송될 주소 |
| 결제한다 | `pay` | 결제 시스템에 승인을 요청하고 결과를 주문에 반영한다 |
| 취소한다 | `cancel` | 결제완료 주문을 취소됨으로 바꾼다 |
| 결제 게이트웨이 | `PaymentGateway` | 결제 시스템에 승인을 요청하는 인터페이스 |
| 배송 게이트웨이 | `DeliveryGateway` | 배송 시스템에 배송을 요청하는 인터페이스 |
| 주문 저장소 | `OrderRepository` | 주문을 찾고 저장하는 인터페이스 |
