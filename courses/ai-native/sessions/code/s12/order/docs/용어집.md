# 용어집

| 용어 | 뜻 | 영문명 |
| --- | --- | --- |
| 주문 | 고객이 상품을 골라 배송지를 정하고 결제해 성립하는 거래 | `Order` |
| 주문 항목 | 주문에 담긴 상품과 수량, 그 주문에 확정된 단가 | `OrderItem` |
| 판매가 | 상품의 현재 가격. 언제든 바뀐다 | `salePrice` |
| 단가 | 주문이 생길 때의 판매가를 그 주문에 확정해 남긴 값 | `unitPrice` |
| 주문 금액 | 항목의 단가 × 수량의 합 | `totalAmount` |
| 배송지 | 주문을 받을 주소 | `Address` |
| 결제 수단 | 결제에 쓰는 카드 | `PaymentMethod` |
| 결제 승인 | 결제 시스템에 승인을 요청해 받는 결과 | `CardApprovalResult` |
| 배송 요청 | 배송 시스템에 배송을 요청하는 일 | `requestDelivery` |

- 판매가와 단가는 **다른 값**이다. 한 이름으로 부르지 않는다.
- 외부 시스템은 상품·결제·배송 셋이다. 업무 코드는 포트 인터페이스로만 안다.
