# 주문 시스템 — 에이전트가 먼저 읽는 지도

이 저장소에서 일하기 전에 아래를 읽는다. 자세한 내용은 가리킨 문서에 있다.

## 무엇을 만드는가

생활용품 쇼핑몰의 주문 시스템이다. 고객이 상품을 골라 배송지를 정하고 결제하면 주문이 성립한다.
상품·결제·배송 시스템은 이미 운영 중이며, 이 저장소는 그 시스템들과 인터페이스로만 통신한다.

## 먼저 읽을 문서

- `docs/glossary.md` — 용어집. 코드의 이름은 모두 여기에서 온다.
- `docs/order-state.md` — 주문 상태 기계. 허용된 상태 전이와 금지된 전이가 있다.
- `docs/business-rules.md` — 업무 규칙. 업무 담당자가 정한 것이며 에이전트가 바꾸지 않는다.
- `docs/dependency.md` — 패키지 의존 규칙.

## 지킬 것

- 업무 규칙과 수용 기준의 **기대값은 사람이 정한다**. 기대값이 틀렸다고 판단되면 고치지 말고 멈추고 묻는다.
- `test/` 아래의 테스트는 지우거나 건너뛰지 않는다.
- 작업은 `./run-tests.sh`가 모두 통과한 상태로 끝낸다.
- 명세에 없는 업무 규칙을 정해야 하면 **멈추고 질문으로 남긴다**.

## 검사(센서)

- `./run-tests.sh` — 컴파일, 수용 테스트, 의존 규칙 검사를 한 번에 돌린다.
- 의존 규칙 검사의 실패 메시지에는 **고치는 방법**이 함께 나온다. 그대로 따른다.
