# 업무 규칙

업무 담당자가 정한다. 에이전트는 이 규칙을 바꾸지 않는다.

## 주문한다 (이미 구현됨)

1. **주문 금액** — 주문이 생길 때의 판매가를 단가로 확정한다. 결제 직전에 판매가가 바뀌어도 주문 금액은 그대로다.
2. **배송 요청** — 결제가 승인된 뒤에만 배송을 요청한다.
3. **결제 거절** — 거절되면 주문은 결제대기에 남고, 다른 결제 수단으로 다시 결제할 수 있다.

## 주문을 취소한다 (이번 작업)

4. **취소할 수 있는 상태** — 결제완료인 주문만 취소할 수 있다.
5. **취소할 수 없는 상태** — 배송중·배송완료·취소됨인 주문은 취소할 수 없다. 이때 주문은 아무것도 바뀌지 않는다.
6. **취소 뒤** — 취소된 주문은 다시 결제할 수 없다.
