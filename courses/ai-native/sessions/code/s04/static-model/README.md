# 정적 모델의 코드와 검사

저장소 루트에서 `node courses/ai-native/sessions/code/s04/static-model/run.mjs`를 실행한다. JDK 17 이상과 Node.js만 필요하다.

개념 모델을 기계적으로 변환한 결과가 아니라 의미를 보존하는 한 가지 Java 예다. `Product`는 외부 상품 시스템에서 받은 정보를 나타내는 로컬 예시이며 상품 시스템 내부 구현이 아니다. `OrderItem.confirm`의 위치, 연관의 참조 방향, 원 단위 long, 계산하는 totalAmount, 불변 record와 목록 복사는 예시의 설계 선택이다. 금액은 원 단위 정수·0 이상, 수량은 1 이상, 생성된 주문은 항목 1개 이상인 교육용 가정을 course-design.md에 명시한다. 상한은 업무 정책으로 정하지 않았고 Java long 범위 초과만 검출한다.

가격 변경과 독립된 단가·총액, 목록 변경 방지, 값의 경계, 전체 항목 합산을 확인한다. 합산 테스트의 반복 항목은 계산 입력이며 동일 상품을 합치는 업무 정책을 정하지 않는다. 결제·배송·상태 전이·영속·동시성·외부 상품 조회 시점의 원자성은 검증하지 않는다. 특히 승인 뒤 배송 요청 실패는 미정이다. 수강생에게 배포할 완성 저장소가 아니라 강의의 코드 발췌 원본이다.
