# 실습 4 — 주문한다 정적 모델

2026-10-23(Asia/Seoul), tools/run-exercise-turn.py와 Codex CLI로 ①~⑤를 실제 실행했다. 모델은 실행 인자로 지정하지 않았다. 단계별 실행 시각·명령·종료 코드는 codex-metadata-NN.json에 있다.

- input-s03.md는 실습 3의 주문한다-요구사항-정의서.md 원문 복사본이다.
- prompt-NN.txt는 실제 피드백을 포함한다. codex-input-NN.txt는 앞선 실제 입력과 응답을 이어 준 전체 입력이다. 응답·이벤트·stderr도 보존한다.
- ②: unitPrice 이름, 원 단위·0 이상 금액, 1 이상 수량·항목 수를 합의했다. 회원 타입·추가 상태를 발명하지 않게 하고 값 타입의 중복 관계선을 정리했다.
- ③: 생성 순간의 단가 확정과 항상 성립하는 합계, 변경 전후 보존을 구별하고 펜 2개·1,000원·서울에 대입했다.
- ④: 중복 항목 병합 정책의 미정을 임의의 허용으로 해석한 문장을 고쳤다.
- ⑤ 첫 최종화의 lead가 단가와 수량을 더하는 것으로 읽혀 원래 실행을 finalization-rounds/01에 보존하고 피드백 후 다시 생성했다. 합계는 단가에 수량을 곱한 금액의 합이라는 뜻을 명시했다. 실제 실행 총 6회다.
- 주문한다-정적모델.md는 최종 codex-response-05.md와 바이트 단위로 같다. 세션 별첨은 이 응답 전체를 4부분에 나누어 제목 단계·목록 들여쓰기만 변환했다.

최초 ①과 ②의 sandbox 실행은 CLI 상태 DB 쓰기 권한 때문에 응답 생성 전에 종료했다. 권한 승인 후 실행한 성공 기록을 보존했다. 모델의 응답을 만든 실패 회차가 아니며 업무 모델의 시행 횟수에 포함하지 않는다.

다음 실습에는 요구사항 정의서와 이 정적 모델을 함께 첨부한다. 단가의 정의와 숫자·개수 제약은 앞 정의서에 반영할 새 합의다. 원래 실습 3의 대화·최종 응답은 수정하지 않았다. 미정 정책은 답을 발명하지 않고 유지한다. Mermaid 원본만 받은 CLI를 시각 검토 완료로 보지 않으며, 실제 도식의 표시는 Production 결과에서 별도로 검토한다.
