# 정기배송 시스템 — 유스케이스: 정기배송을 신청한다

- **주 액터** — 고객
- **지원 액터** — 상품 시스템, 결제 시스템
- **사후조건** — 정기배송이 확정되고 기간 동안의 배송 회차가 예정으로 생긴다.

## 기본 흐름

1. 고객이 상품을 조회한다. 시스템은 상품 시스템에서 상품 정보를 받아 보여 준다.
2. 고객이 상품과 수량을 담는다(1~2 반복).
3. 고객이 배송 주기·첫 배송일·기간·배송지를 입력한다.
4. 고객이 결제 수단을 골라 결제한다. 시스템은 결제 시스템에 전체 회차 금액의 승인을 요청한다.
5. 시스템은 정기배송을 확정하고, 배송 회차들을 만들어 고객에게 신청 결과를 보여 준다.
