# 정기배송 시스템 — 요구사항 정의서(신청한다)

생필품을 고객이 정한 주기로 배송하는 정기배송 시스템이다. 첫 기능은 **정기배송을 신청한다**(결제 포함)다. 이 저장소에는 아직 코드가 없다.

## 기능 요구

- **신청** — 상품·수량·배송 주기·첫 배송일·기간·배송지를 정해 신청한다.
- **결제** — 결제 수단을 골라 전체 회차 금액을 한 번에(일시불) 결제한다.

## 업무 규칙

- **배송 주기** — 1~28일, 일 단위
- **배송일** — 첫 배송일은 신청 다음 날부터 7일 안에서 고르고, 이후는 주기마다 정해진다.
- **기간** — 1~12개월. 만료일은 첫 배송일 + 기간의 전날이다.
- **회차 금액** — 신청 때의 가격 × 수량. 기간 끝까지 같은 금액을 쓴다.

## 외부 시스템

| 외부 시스템 | 정기배송 시스템이 하는 일 |
|---|---|
| 상품 시스템 | 상품 정보·가격을 조회한다(동기) |
| 결제 시스템 | 결제 승인을 요청한다(동기) |
| 배송 시스템 | 회차마다 배송을 요청한다(비동기), 배송 시작·완료를 통보받는다 |
