# 실습 7 — 주문한다 설계와 작업 단위

2026-10-24(Asia/Seoul). `tools/run-exercise-turn.py`와 Codex CLI로 실제 실행했다. 단계별 시각·명령·종료 코드는 `codex-metadata-NN.json`에 있다. 성공한 실제 실행은 총 6회(①~④ 4회, ⑤ 최종화 2회)다.

- 입력 `input-s03.md`·`input-s04.md`·`input-s05.md`·`input-s06.md`는 실습 3·4·5·6의 실제 최종 MD 복사본이며 원본과 바이트 단위로 같다. ①에 넷을 함께 첨부해 프롬프트 하나가 38KB다.
- `prompt-NN.txt`는 사람이 실제로 보낸 입력이다. 앞 실습의 최종 MD를 통째로 붙인 ①은 노트에 싣지 못하므로, **그대로 재현하려면 이 파일을 그 자체로 입력으로 쓴다.** `codex-input-NN.txt`는 앞선 실제 입력과 응답을 이어 준 전체 입력이다. 응답·이벤트·stderr도 보존한다.
- ①은 책임 배치·설계 시퀀스·인터페이스·오퍼레이션 계약을 한 번에 냈다. ②~④에서 사람이 포트를 하나로 묶지 않을 것, 느슨한 대역이 통과시키는 금액을 계약으로 막을 것, 미정을 분기나 기대값으로 메우지 않을 것을 요구했다.
- ⑤의 첫 최종화는 오퍼레이션 계약의 사후조건 셋을 한 칸에 담아 표로 읽히지 않았다. 그 실행은 `finalization-rounds/01`에 보존하고 배치만 고쳐 다시 생성했다.
- 작업 단위가 **다섯**이다. 강의의 넷과 다른 점은 주문 생성과 주문 결과 확인을 단위로 둔 것, 확정 불가를 단위 4로 둔 것이다. 설계가 앞 실습의 미정을 늘리지도 줄이지도 않았다.

`주문한다-설계.md`는 `codex-response-05.md`와 바이트 단위로 같다. 세션 별첨은 이 응답 전문을 나누어 제목 단계와 블록 표식만 Session Source 형식으로 바꿨고 문장·도식·강조는 편집하지 않았다. 인터페이스 선언은 실행한 원본이 아니라 응답의 제안이므로 코드 발췌 검사 대상이 아니다.

실습 시간은 미계측이다. 실제 실행 횟수는 저자의 보완 기록이며 수강생의 필수 프롬프트 횟수가 아니다. 다음 실습은 이 설계와 작업 단위를 위임의 입력으로 읽는다. Mermaid 코드만 받은 CLI 응답을 시각 검토 완료로 보지 않으며 실제 PPT의 도식 표시는 Production에서 별도로 확인한다.
