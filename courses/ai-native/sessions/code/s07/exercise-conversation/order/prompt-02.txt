[앞선 질문에 대한 답]
1. 본인 주문 권한 검사의 적용 여부는 미정이다. 설계에서 정하지 말고 검사할 자리가 비어 있다고만 적어라.
2. 회원·비회원과 본인 확인 정보의 타입도 미정이다.
3. 확정 불가 결과 뒤의 재결제 허용 여부는 미정이다.
4. 승인 뒤 저장이나 배송 요청이 실패할 때의 처리도 미정이다.
5. 승인·거절 이력의 영속은 이번 범위가 아니다. 주문 결과 확인은 현재 상태와 확정 값으로 한다.
6. 유스케이스 조정자는 업무 패키지 order에 둔다. 포트를 업무 패키지가 소유한다는 아키텍처 결정과 같은 근거다. 이름은 네가 정하고 근거를 적어라.

[추가 질문·수정 요청]
책임 배치의 근거를 정보 전문가와 컨트롤러로 다시 적어라. 주문 금액 계산, 단가 확정, 상태 전이와 금지, 사건 수신과 호출 순서, 조회와 저장, 외부 승인·배송 요청을 각각 어느 객체가 맡고 왜 그런지 한 줄씩 밝혀라. 그 값을 아는 객체가 계산하는지, 값을 넘겨 받아 계산하는 객체가 없는지 확인해라.
