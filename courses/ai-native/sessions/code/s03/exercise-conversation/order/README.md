# 실습 3 — 주문한다 요구사항 정의

2026-10-22에 `tools/run-exercise-turn.py`와 Codex CLI로 실제 실행했다. 실행 명령·시각·종료 상태는 각 `codex-metadata-NN.json`에 있다. 모델 이름은 실행 인자로 지정하지 않았다.

- `input-s01.md`: 실습 1에서 확정한 업무 조건 원문.
- `prompt-01.txt`~`prompt-05.txt`: 실제 요청. `codex-input-NN.txt`는 대화 맥락을 포함한 실제 입력이다.
- `codex-response-NN.md`: 실제 응답 원문. 이벤트·표준 오류·메타데이터도 단계별로 보존했다.
- ②에서 임의로 정한 재고 검사 시점을 수정했고, ③에서 네 수용 예를 구체화했다. ④에서 품질 조건과 접근 범위를 확정했다.
- ⑤의 첫 최종화는 모델·설계·코드 산출물을 기능 제외 범위와 혼동했다. 이 실행 전체를 `finalization-rounds/01/`에 보존하고 피드백을 넣어 ⑤를 다시 실행했다. 총 실제 실행은 6회다.
- `주문한다-요구사항-정의서.md`는 최종 `codex-response-05.md`와 바이트 단위로 같다. 세션 별첨도 제목 수준과 목록 들여쓰기만 조정해 전문을 수록했다.

결제 거절·재시도와 배송 요청 중복 방지는 확정 조건으로 유지하고, 배송 시스템 장애 이후의 처리 정책은 미정으로 남겼다. 실제 응답을 사후 편집하지 않았다.
