## 2. 반복 실행 횟수와 조건

- 독립 실습 실행 **두 번**: A=`run-03`, B=`run-04`. 두 실행 사이에 응답이나 보완본을 공유하지 않았다. 동일한 첫 프롬프트에 실습 1·2의 원문을 모두 첨부했다. 두 원문의 공백 앞뒤를 제외한 내용 일치와 두 첫 프롬프트의 바이트 일치를 확인했다.
- 환경: macOS, Codex CLI `0.149.1`, 기존 `tools/run-exercise-turn.py`. `--ignore-user-config --ephemeral --sandbox read-only --skip-git-repo-check --config project_doc_max_bytes=0 --json`을 사용했다. 도구 탐색·파일 쓰기는 프롬프트로 금지했으며 실제 이벤트에 도구 실행 항목은 없다. CLI의 기본 모델을 사용했고 모델 식별자·temperature·seed는 지정하지 않았으며 이벤트에도 모델 식별자가 나오지 않는다. 따라서 같은 명령·입력·환경의 반복이며 특정 모델 버전까지 고정한 실험이라고 주장하지 않는다.
- 실행기는 매 호출마다 독립 CLI를 시작하고 해당 실행 내부의 이전 프롬프트·실제 응답만 다음 입력에 재구성한다. `prompt-NN.txt`는 요청, `codex-input-NN.txt`는 실행기 안내·앞 대화를 포함한 전체 실제 입력이다. 응답·이벤트·표준 오류·시각·종료 코드를 모두 보존했다.
- 후속 답변은 Course Design 공통 전제와 기존 S03 확정 대화에 근거한 사례 값·상태·품질 조건만 제공했다. H·B·F·E·G·I, 재고 판단 시점, 승인 전 재고 부족 등의 정책은 새로 확정하지 않았다. 피드백은 각 실행의 실제 응답을 검토한 뒤 따로 작성했다.
- ①~⑤는 고정 대화 횟수가 아니므로 A는 3턴(초안→보완→최종), B는 4턴(초안→보완→추가 보완→최종)으로 진행했다. 원고의 최종 요청은 A의 `prompt-03.txt`, B의 `prompt-04.txt`다.
- 별도 보존: `run-01`은 CLI 초기화 권한 오류로 종료 코드 1이며 AI 응답이 없다. 상태 DB 쓰기·in-process app-server 초기화가 차단됐다. 같은 실행기를 권한 승인 후 별도 폴더에서 실행했다. `run-02`는 실습 2를 요약해 첨부한 예비 초안 1턴이므로 독립 실습 반복 횟수에 포함하지 않는다. 예비 응답에서도 재고 확인 시점 고정과 미정 분기의 수용 기준화가 관찰됐다. 실패와 예비 기록은 덮어쓰지 않았다.
- 기존 2026-10-22 `order/` 기록의 6회는 한 대화의 단계·최종화 재시도다. 독립 실습 여섯 번으로 세지 않았다.

## 4. 대표 실행과 선정 이유

**B의 `run-04/codex-response-04.md`를 대표 후보로 선정한다.** 첫 초안에서 재고 시점을 고정하지 않았고, 추가 검토에서 드러난 순서 모순·제외 누락을 실제 대화로 고친 뒤 최종 응답에서 유지했다. A보다 한 턴이 더 필요했지만 핵심 업무 규칙·용어·품질 조건·미정 구분이 더 정확하다. CLI 성공 여부나 짧은 생성 시간만으로 선택하지 않았다.

각 실행의 `주문한다-요구사항-정의서.md`는 해당 최종 응답과 바이트 단위로 같다. 대표 후보는 기존 `order/주문한다-요구사항-정의서.md`나 다음 세션의 입력 파일에 반영하지 않았다. Human 검토·승인 전이므로 최종 승인본이 아니다.

## 5. 임시 답안과 실제 결과의 차이

- 공통: 사용자 스토리 1개, 주문 생성/성립 분리, 2,000원 유지, 결제대기/결제완료, 배송 1/1/0/총1회, 품질·접근 조건 및 H·B·F·E·G·I의 미정 유지가 일치한다.

- B는 입력에 없는 정책을 정하는 대신 빈 장바구니·수량 제한·통화/세금/반올림·중복 요청·배송지 검증 등 추가 질문을 더 남겼다. 임시 답안보다 미정 목록과 전체 문서가 길다. 이 질문은 정책 확정이 아니다.

## 6. Human 승인이 필요한 사항

- 품질 조건의 실제 제공 출처를 투입물·안내에 연결할 범위와 방법.
- 승인된 같은 주문 사례를 유지하면서 지침의 별개 사례 규칙 및 사용자 이야기/사용자 스토리 용례를 정합화할 방향. 이번에는 지침과 의미를 바꾸지 않았다.
- 대표 후보 B를 임시 별첨 답안 및 후속 세션 입력의 교체 대상으로 삼을지에 대한 내용 승인. 추가 미정 질문의 범위와 오탈자 처리도 검토 대상이다. 실제 응답 원문은 계속 보존해야 한다.
- 시연의 생략 표식·10pt 표 형식 및 요약의 모델 보완 표시를 보완할 범위. 이번에는 원고·renderer를 수정하지 않았다.
