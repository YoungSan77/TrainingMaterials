# 실습 3 — 실제 대화와 최종 도메인 모델

- `templates.json`은 수강생용 기본 문구, `prompt-*`와 `codex-response-*`는 실제 입력·응답이다.
- `conversation.md`에는 ①~④와 ⑤의 세 차례 생성·검토를 포함한 실제 7회 대화를 보존한다. 수강생의 필수 횟수가 아니다.
- `finalization-rounds/01`·`02`는 최종 MD에 피드백하기 전 실제 응답과 요청이다. 현재 최종 파일의 대화 이력에 필요하므로 유지한다.
- `정기배송-최초신청-도메인모델.md`는 마지막 `codex-response-05.md`와 동일하며 실습 4의 입력이다.
- `input-s02.md`는 이 예시를 처음 실행했을 때의 요구사항 스냅샷이다. 실제 과거 입력을 현재 파일로 덮어쓰지 않는다.
- 용어와 업무 규칙을 구분하고 클래스·시퀀스·상태 머신 원본을 보존한다. 실제 최종 요청은 기본 문구에 검토 피드백과 도식 형식을 보완한 예다.

교재 원천은 `sessions/s03.md`다. 별첨은 용어·업무 규칙 절 전체와 세 다이어그램 원본을 발췌했으며 설명문은 최종 MD에 보존한다. 과거 검토본·실패 백업의 복구 위치는 저장소의 `REPOSITORY-STATUS.md`를 본다.
