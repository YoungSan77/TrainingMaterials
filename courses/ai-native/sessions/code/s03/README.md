# 도메인 모델의 코드 연결 예

`DomainModelExample.java`는 세션 03 「도메인 모델」의 발췌 원본이다. JDK 17 이상, 외부 라이브러리 없이 실행한다. 저장소 루트에서:

```sh
java courses/ai-native/sessions/code/s03/DomainModelExample.java
```

`main`은 판매가 변경 후 금액 보존, 승인 후 배송 요청, 거절 후 배송 금지, 같은 주문의 재결제를 검사한다. 실패하면 AssertionError로 종료한다.

교육용 입력은 양의 정수 원화 금액·수량과 결제대기 주문에 한 번 전달되는 승인/거절 결과다. 주문 식별·배송지·상품 참조 보관·영속·실제 결제 및 배송 연동은 생략했다. `Runnable`은 요청 횟수와 호출 순서를 관찰하는 테스트 연결점이다. 승인 후 배송 요청 실패의 보상·재시도 정책은 미정이므로 구현하거나 기대값을 정하지 않았다. 입력 검증·오버플로·동시성·중복 결제도 운영용 보장을 제공하지 않는다.

`demo-results/`는 이전 세션 구성에서 생성한 별도 기록이다. 현재 원고의 교육용 초안 검토 예나 이 Java 실행 결과의 근거로 사용하지 않는다.
