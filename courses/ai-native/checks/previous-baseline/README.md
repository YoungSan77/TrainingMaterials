# 이전 기준선의 세션 원고 (비교 자료)

여기 있는 `s02.md`~`s12.md`는 **2026-11-26 재설계 이전** 편성의 Deck 원고다. `sessions/`에서 2026-11-27에 옮겼다.

**현재 승인 정본이 아니다.** 세션 편성이 바뀌어 번호와 이름이 모두 달라졌으므로 번호로 새 세션에 대응시키지 않는다(`../STATUS.md` 「비교 자료와 복구」).

## 왜 `sessions/`에서 옮겼나

정본 폴더에 정본이 아닌 원고가 섞여 있어서 실제로 문제가 생겼다.

- 과정 전체를 검사하면 이 원고들이 **승인 Curriculum과 다른 세션명**으로 오류를 냈다.
- 별첨 `sessions/references.md`가 이 원고들이 쓰는 **이전 선정의 출처 레이블**을 요구해 오류 6건이 났다.
- Renderer가 이 원고들의 세션명(`03. 요구사항`·`04. 도메인 모델 — 정적 관점`·`05. 도메인 모델 — 동적 관점`)으로 조판을 바꾸고 있었고, 새 편성에서 같은 번호를 쓰는 다른 세션에 **엉뚱하게 걸릴 상태**였다.

지금 `sessions/`에는 현행 원고만 있다. 이 폴더의 원고는 검사·렌더링의 대상이 아니다.

## 쓰는 법

새 세션을 쓸 때 **참고할 수 있지만 기준으로 삼지 않는다.** 재사용할 내용(사례·인용·설명)이 있으면 현재 지침과 승인 Course Design·Curriculum에 맞는지 확인한 뒤 새 원고에 다시 쓴다. 확인한 인용은 `references/verified.json`에 남아 있으므로 `node tools/citations.js courses/ai-native <저자>`로 찾는다.

이전 설계 문서(`course-design.md`·`curriculum.md`)의 내용은 Git 커밋 `764ac26`에 있다.
