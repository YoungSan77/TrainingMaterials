# S03 일반 본문 표 0.15cm 여백 정정

최신 제작 지침에 따라 일반 본문11표의 머리글·본문121셀 전체에 `marL=marR=marT=marB=54000`을 적용했다. 기존5400은0.15mm였으며 이번54000은0.15cm(1.5mm)다.3쪽10셀도 전수 포함했다. 열별 최장 표시 텍스트 폭+좌우 여백을 계산하고 그 합을 표 개체 폭으로 사용한다. 이전 전체 폭을 채우는 재분배는 하지 않는다. 새 상하 여백에서 행 높이·표 높이를 다시 계산했으며 모든 본문 행이 일반 표 최소0.8cm 안에 들어가 기존 후속 설명 위치는 유지된다.

실제 변경 장은3·6~9·12~15·21·23쪽이다. 시연·판단표·별첨과 범위 밖19장은 생성 전 XML과 동일하다. 원고·실제 응답·기존 미커밋 변경을 보존했고 커밋·푸시하지 않았다.

검증 스크립트와JSON은 같은 basename으로 보존했다.121셀의 네 여백 속성과 font/content 보존, frame cx=열 폭 합 및 frame cy=행 높이 합을 확인했다. 최종PDF에서 모든 대상 행이 한 줄로 출력되고 문구 누락이 없음을 전수 대조했다. 변경11장만 렌더 검토해 잘림·불필요한 줄바꿈·표 뒤 설명 겹침 없음. 증거는 `out/review/s03/s03.pdf`, 해당 PNG11장, `out/s03-cm-bbox.html`이다.

전체 테스트304/304 통과, 자동 검사 오류0·기존 경고51. 이번 셀 여백 범위의 남은 불일치는 없다. 기존 원고 경고와 별첨 설명의30쪽 이월은 그대로다. 생성1회·렌더1회·시각 검토11장.
