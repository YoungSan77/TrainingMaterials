# 시연 판단표와 이번 실제 응답의 대응

대상은 `courses/ai-native/sessions/s03.md`의 「초안의 제안을 업무 결정과 대조한다」다. 근거는 이번 실행의 `code/s03/exercise-conversation/production-2026-11-16/demo/codex-response-01.md` 전문이다. 응답을 기존 번호에 맞춰 다시 생성하거나 원문을 편집하지 않았다.

현재 판단표의 **5행 모두 식별자 또는 대상 범위가 다르다**. 「S03 제작 기준」과 원고 강사 노트에 따라 아래 수정안을 작성자에게 전달한다. 승인된 업무 결정·미정 정책은 바꾸지 않았으며, 원고의 판단표는 자동 교체하지 않았다.

| 현재 행 | 이번 실제 응답 | 판정 |
|---|---|---|
| BR-1~3 | BR-01~09. 금액은 BR-01~03·08, 승인 뒤 배송은 BR-04·07, 거절 뒤 유지·재결제는 BR-05·06이다. BR-09 중복 방지는 회의 메모에서 확정한 규칙이 아니다. | 번호·범위 불일치 |
| Q1 생성, Q6 승인 뒤 상태 | 9절 질문 1이 생성 시점, 질문 2·3이 상태다. 질문 6은 배송비·세금·할인·쿠폰·포인트 포함 여부다. Q 접두어는 원문에 없다. | 질문 6 의미 불일치 |
| Q12 배송 실패 | 질문 12는 결제 응답 지연·결과 불명이다. 배송 재시도는 20, 승인 뒤 배송 실패 상태·운영 처리는 21이다. | 질문 대상 불일치 |
| Q15 취소·환불·배송지 변경 | 질문 15는 상품 판매 가능 여부·재고 확인이다. 취소·환불·배송지 변경은 2절에서 AI가 미확인 기능을 제외로 제안한 목록에 있다. 미정을 제외로 둔 것 자체도 비판적으로 검토해야 한다. | 질문 대상·미정/제외 분류 불일치 |
| US-1~3 | US-01 주문, US-02 금액 보존, US-03 승인 후 배송, US-04 거절 후 재결제의 네 스토리다. | 식별자·개수 불일치 |

## 작성자용 판단표 수정안

아래는 첫 열의 관찰 근거를 새 응답에 맞춘 제안이며, 사람의 결정은 기존 것을 유지한다.

| 실제 응답에서 확인한 것 | 사람의 판단 | 정의서 반영 |
|---|---|---|
| BR-01~03·08은 금액 보존, BR-04·07은 승인 뒤 배송, BR-05·06은 거절 뒤 유지·재결제를 적었다. | 채택 | 생성 시 금액 확정, 승인 후 배송 요청, 거절 후 동일 주문 재결제를 기록한다. |
| 9절 질문 1은 주문 생성 시점을, 질문 2·3은 주문 상태와 승인 뒤 상태를 묻는다. | 정의 | 배송지 확정 시 주문을 생성하고, 카드 승인 뒤에는 결제완료로 기록한다. |
| 9절 질문 20·21은 배송 요청 재시도와 승인 뒤 배송 실패의 상태·운영 처리를 묻는다. | 미정 | 재요청과 고객 통지 정책을 결정할 질문으로 남긴다. |
| 2절은 확인하지 않은 취소·환불·배송지 변경을 제외로 제안했다. | 범위 확인 | 취소·환불은 제외한다. 결제대기 주문의 배송지는 변경할 수 없다. |
| US-01~04는 AI가 제안한 분할이다. | 스토리 하나 유지 | ‘주문한다’에 주문·결제·재결제 흐름을 담는다. |

추가 관찰: 응답은 미확인 기능을 제외로 제안하고 BR-09의 배송 중복 방지를 확정 규칙처럼 적었다. 원문을 실제 응답으로 보존하되 확정 요구사항으로 승인한 것으로 보지 않는다.
