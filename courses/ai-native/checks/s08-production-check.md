## 이 세션의 사례는 실제 실행에서 나왔다

실습을 `/tmp/s08-delegation/repo`에서 실제로 돌렸다. 투입물은 `code/s07/exercise-conversation/order/`의 03~07 산출물이고, 다섯 번의 프롬프트·응답·도구 호출 기록을 `code/s08/exercise-conversation/order/`에 보존했다(`prompt-01..05.txt`, `codex-response-01..05.md`, `codex-events-01..05.jsonl`, `codex-session.jsonl`). 별첨의 「실제 LLM 응답」은 마지막 응답이 만든 `주문한다-위임기록.md`의 발췌이며 문장을 고치지 않았다.

실행이 드러낸 것은 구성안이 예상한 것과 **반대 방향**이었다.

- **허용으로 적은 커밋이 거절됐다** — `git add`가 `.git/index.lock` 생성에서 `Operation not permitted`로 막혔다.
- **금지로 적은 저장소 밖 쓰기가 통과했다** — `printf … > ../order-config/application.properties`가 출력 없이 exit 0으로 성공했다.

그래서 세션의 Anchor Message를 "금지는 글로 적는 것으로 막히지 않는다 — 막으려면 환경이 거절해야 한다"로 두고, 「09. 맡긴 결과 보기」의 「환경이 거절한 것과 하지 않은 것」에서 두 결과를 나란히 읽게 했다. `course-design.md`의 S08 사례 결정도 "환경이 거절한다"에서 이 실행의 두 결과로 고쳤다.

## 함께 고친 것

- **`course-design.md` S08** — 사례 결정과 세션별 사례 표(08행)를 실제 실행에 맞췄다. 금지한 저장소 밖 쓰기는 통과하고 허용한 커밋은 거절된다. 다이어그램·코드 항목도 「거절된 행동과 통과한 금지의 기록」으로 바꿨다.
- **renderer — 도식 위 코드** — `builder.js`의 `sourceCode`가 코드 뒤에 붙는 본문까지 미리 예약해 자리를 재던 것을, 예약으로 들어가지 않으면 **예약 없이 코드만 먼저** 시도하게 고쳤다. 도식을 반복하며 코드를 쪼개는 대신 뒤따르는 본문을 다음 장으로 보낸다. 회귀 테스트 "text after a stacked diagram's code moves to the next slide instead of splitting the code"를 더했다(`code-diagram.test.js`). 이 수정으로 「돌아온 구현 코드」가 3장에서 2장이 됐다.
- **`code/s08/delegation/`** — 실행이 돌려준 구현을 그대로 옮겨 컴파일·검사한다(`run.mjs`). 실행의 `OrderStatus`는 첫 단위가 쓰는 둘만 선언했고, 예제 원본은 관통 사례의 상태 넷(`PENDING_PAYMENT`·`PAID`·`IN_DELIVERY`·`DELIVERED`)을 유지하도록 채웠다. 채운 사실은 원고의 강사 노트와 `run.mjs` 주석에 밝혔다 — 값이 줄면 다음 세션이 같은 이름을 다른 뜻으로 쓴다.
- **별첨** — 마지막 응답의 절 「거절된 행동과 멈춘 질문」을 둘로 나눴던 것을 한 topic으로 합쳤다. 한 항목만 남는 장이 생겼기 때문이고, 원문의 절 제목과도 맞는다.
- **23·24장을 한 장으로** — 「저장소와 빌드 구성을 맡긴다」가 코드 블록 때문에 두 장으로 갈렸다. 운영 안내(실습실 내려받기 사본)를 강사 노트로 옮기고 도입·단계 문장을 줄여 한 장에 넣었다. 합치면서 줄이 끝에 홀로 남던 문장부호와 한 글자 고아도 없앴다. 39 → 38 → 37장.

## 별첨이 5번째 실행의 결과인지 확인

`주문한다-위임기록.md`가 **⑤의 응답이 만든 파일**인지 세 가지로 확인했다.

- `codex-events-01..05.jsonl` 가운데 이 파일이 나오는 것은 **05뿐**이다. ⑤의 `file_change` 항목이 `주문한다-위임기록.md`를 `add`로 만들고 `OPEN_QUESTIONS.md`를 지웠다.
- 파일의 수정 시각(15:26)이 ⑤의 구간(`06:25:32Z`~`06:27:20Z`, `codex-metadata-05.json`) 안에 있다.
- 보존한 사본과 실행 폴더의 원본이 **바이트 단위로 같다**(2,414바이트, `diff` 없음).

별첨의 발췌를 원본과 문장 단위로 대조해 **어긋난 두 곳을 찾아 강사 노트에 밝혔다**.

- 「검사 출력」 — 원본은 `명령:`·`출력:` 두 블록인데 슬라이드는 한 블록으로 이어 붙였다. 명령과 출력 문장은 그대로다.
- 「거절된 행동과 멈춘 질문」 — 코드 블록이 있는 저장소 밖 쓰기 항목을 앞에 모으고 질문 항목을 뒤로 옮겼다. 문장은 그대로이고 **순서만** 바뀌었다.
- 나머지(「위임 계약」 전문, 「만든 파일」에서 `.gitkeep` 줄을 뺀 것)는 원래 강사 노트에 발췌 범위가 적혀 있었다.
