## 세션 사이 참조

옛 원고의 세션 참조는 220곳이다. 세션명만 바꾸는 치환은 쓸 수 없다 — 갈라지는 세션은 목적지가 topic마다 다르고, 새 topic 번호는 그 세션을 쓸 때 생긴다.

- 참조는 **그 원고를 다시 쓸 때 함께 고친다.** 아직 쓰지 않은 세션을 가리키는 참조는 Production이 경고로 남기므로, 전부 끝난 뒤 `--check`로 한 번에 확인한다.
- 세션을 하나 끝낼 때마다 `node engine/production/src/cli.js --check courses/ai-native/sessions/s*.md`로 남은 오류 수가 줄어드는지만 본다. 전면 보완 중에는 오류 0이 되지 않는다.
- 완료 조건은 열두 세션과 별첨이 모두 **오류 0·경고 0**으로 렌더링되는 것이다.

## 작업 순서

1. s01부터 s12까지 순서대로. 세션마다 인용 확인 → 구성안 승인 → 원고 → 렌더링.
2. 예시 코드는 새 세션 번호에 맞춰 `sessions/code/sNN/`을 다시 배치한다. 옛 번호의 코드 폴더는 옮기기 전까지 그대로 둔다.
3. 실습도 새 번호로 다시 매긴다. 실습 2·3이 요구사항 정의서와 도메인 모델을 **직접 만드는** 것으로 바뀌었다(옛 구조는 모델 패키지를 받아서 시작했다).
4. 전부 끝나면 이 문서를 지운다.
