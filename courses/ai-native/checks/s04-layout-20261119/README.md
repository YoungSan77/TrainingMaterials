## 공통 구현과 지침

S04 좌표 보정·특정 문자열 허용·경고 무시는 추가하지 않았다. 과정별 기준 파일은 변경하지 않고, 공통 규칙을 `guides/production-guide.md`의 「표의 행 높이와 열 너비」에 보강했다. 새 센서는 `guides/agentic-repository-guide.md`에 등록했다.
