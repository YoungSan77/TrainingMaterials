# S03 요구사항 — 최신 원고 통합 제작 검증

입력은 현재 `courses/ai-native/sessions/s03.md`, `guides/session-authoring-guide.md`, `guides/production-guide.md`다. 원고와 두 지침의 이번 작업 시작 시 내용을 보존했다. 산출물은 `courses/ai-native/sessions/s03.pptx`·`s03.qa.json`이며30장이다. 파일 시각·SHA256·renderer버전은 `manifest.json`에 있다. 기존 미커밋 변경을 유지했고 커밋·푸시하지 않았다.

## 기존 실행의 재사용

먼저 `courses/ai-native/sessions/code/s03/exercise-conversation/production-2026-11-16/README.md`를 읽고 연결된 기록을 대조했다. 시연 입력과 실습 첫/마지막 요청, 두 첨부 원본 바이트가 현재 원고·기준 입력과 일치한다. 네 턴의 종료코드0과 응답 전문/JSONL agent_message 일치, 기존 시연·별첨 발췌의 원고 내 완전 일치도 확인했다(`execution-verification.json`). 재실행0회다. 최초 실행 기록에 적힌38장·옛 판단표 피드백은 당시 이력이며 현재 원고/제작 기준으로 사용하지 않았다.

## 남은 불일치와 원고 판단 항목

- 표 경고21건은11절 시연 판단표와 별첨 실제 응답의 원문 셀이다. 실제 줄바꿈과 적합 행 높이로 출력됐고150셀 렌더검사는 통과했다. 한 줄 표 원고 정책을 맞추기 위해 원문을 축약하지 않았다.
-11절 ‘인수 조건:’4곳과 별첨 ‘공통 사례는 다음과 같다.’의 목록 머리말 경고5건은 저장된 실제 응답의 문구/구조다. 실습 답을 재작성하거나 강조를 더해 없애지 않았다. 원문 보존과 일반 목록 저작 정책의 적용 구분은 향후 검사 정합성 항목이다.
