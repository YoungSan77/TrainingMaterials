# AI-native SW 공학 — Curriculum / Session Architecture 분리 초안

**검토 이력 · 승인 반영 완료(2026-11-25).** 편성·인계와 S05·S08/S09·S12의 범위, S01 저장소 생성 및 2일차 시작 결정을 [승인 Curriculum](../curriculum.md)에 반영했다. 아래 본문은 승인 전 검토 자료다. 승인 결과와 해시는 [전환 기록](ai-native-transition.md#2026-11-25-정본-전환과-승인), 전환 직전 입력은 [보존본](course-design-before-split-20261125.md)을 참조한다.

## 과정 개요

주문한다 사례를 사용해 무엇을 맡길지 고르고, 요구사항·정적/동적 관점·아키텍처·설계를 결정한 뒤, 계약과 권한을 갖춰 업무를 맡긴다. 검사로 완료를 판정하고, 비용과 평가로 위임을 다시 판단한 뒤, 대표 작업 단위와 정책 보완으로 종합한다. S01은 과정의 지도를 제공한다. S01~S07은 결정과 초안, S08~S12는 실행과 증거를 중심으로 둔다. 순서는 학습 편성이다. 뒤 활동에서 발견한 근거는 앞 결정으로 환류한다.

네 요소의 기존 분담을 유지한다. 명세·모델·맥락은 S03~S07, LLM과 에이전트는 S02·S08, 권한과 변경 통제는 S09, 실행 가능한 검사는 S10이 담당한다. S11은 위임을 지속할지 평가하고 S12는 전체 흐름을 종합한다.

## 세션 구성과 시간

## 세션 간 경계와 원전 인계

- S03은 범위·제외·미정 및 수용 기준을 정한다. S04는 개념과 관계, S05는 사건과 전이로 구체화한다. 두 모델 관점은 서로를 검증하며 정적 모델과 동적 모델을 별개 업무 모델로 분리하지 않는다.
- S06은 패키지 경계, S07은 객체 책임과 협력을 가르친다. 같은 원칙을 다른 결정에 적용한다. S09의 사전 차단과 S10의 사후 탐지, S02의 비용 구조와 S11의 비용·효과 판단도 각각 역할을 구분한다.
- 기존 기준 원전 활용 위치를 이어받는다. 위임 형태 [Anthropic 2024]는 S02·S08·S09, 맥락 [Anthropic 2025c]는 S02·S08, 명세 [Böckeler 2025]는 S03, 검사 [Böckeler 2026a]는 S10, 평가 [Anthropic 2026a]는 S11, 위험 [NIST 2023]은 S09·S11, 아키텍처 [Martin 2000]은 S06·S07에 연결한다. 보완 자료 활용 위치와 용어의 정의 세션은 현행 [Course Design](../course-design.md)의 「기준 원전과 참고 자료」 및 주제별 용어표에서 읽어 해당 DD 검토 시 이관한다. 공통 정의·판본·적용 결정은 [Course Design 후보](course-design-draft.md)에서 소유한다.
