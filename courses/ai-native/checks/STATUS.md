## 재검토 방식

- 2026-11-26 **원점 재검토** 결정. 이전 설계의 교육 목표·성과(O01~O12)·목차·세션 구성·시나리오·실습 구조를 출발점으로 삼지 않았다. 보편적 SW 공학 원칙과 AI 등장으로 인한 변화에서 독립적으로 도출한 뒤 비교했다.
- **단계별 결정 경과** — ① 과정의 정체성과 교육 필요성 ② 교육 대상과 선수지식 ③ 교육 목적 및 목표 ④ 핵심 교육 내용과 범위 ⑤ 교육 접근법 ⑥ 성과 처리(측정하지 않음) ⑦ 과정 구성과 시간 배분. 각 단계를 Human과 논의해 합의했고 결과는 `course-design.md`와 `curriculum.md`가 소유한다.
- **합의된 정체성** — AI-native SW Engineering은 SW 공학의 보편적 원칙을 기반으로 인간과 AI의 능력 및 제약을 고려하여 소프트웨어 개발·딜리버리·운영·진화의 수행 방식을 재구성하는 공학적 접근이다.
- **합의된 편성** — 순수 교육시간 700분(50분 블록 14개), 강의·토의 395분 · 실습 280분(40.0%) · 환경 설정 25분. 핵심 SW 공학 활동 10블록 500분(71.4%). 세션 12개, 실습 12개.
- **수강생 평가 없음** — 교육 성과를 측정하거나 평가하지 않는다. 최소 달성선·역량 입증 기준·평가표를 설계하지 않는다. 점검항목은 학습 도구다. 과정 자체의 품질 검증은 성과 측정과 구분한다.

- 실습에 투입할 자료의 데이터 정책 — 과정이 제공하는 사례로 한정하는 것이 안전하다

- **Claude Code Desktop 앱 경로** — 터미널 없이 쓰는 경로가 공식 문서에 있는 것은 확인했으나 **교육장 환경에서 검증하지 않았다.** 검증 전에는 수강생에게 안내하지 않는다. 설치 자체가 막힌 경우에는 이 경로도 막히므로 대체가 되지 않는다
- **Team 계정의 CLI 로그인** — Claude Code는 Pro·Max·Ultra·Team·Enterprise·Console 계정을 요구하고 무료 플랜을 제외한다(공식 문서, 2026-11-26 확인). **Team 계정으로 CLI에 로그인할 때 관리자 설정이 필요한지는 확인하지 않았다.** 과정은 API Key를 쓰지 않으므로 설정 전에 `ANTHROPIC_API_KEY`가 설정되어 있지 않은지 확인한다
- **실제 CI 실행 조건** — CI 계정과 저장소 접근 권한(수강생 개인 계정인지 교육용 조직 계정인지), 교육장 네트워크에서 CI 서비스 접근 가능 여부, 실행 시간 한도, 실행 환경. **실패 시 대체 경로**는 로컬 테스트 실행이며, **로컬 실행을 실제 CI 실행과 동일하게 취급하지 않고 그 차이를 설명한다**

파일이 있다는 사실만으로 현재 설계의 승인이나 완료를 판단하지 않는다.
