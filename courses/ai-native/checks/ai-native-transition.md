## 이전 전환 검토

이 목록은 `courses/ai-native/course-design.md`와 `sessions/s01.md`–`s05.md`, 과정 제작 기준과 기존 실행 기록을 읽고 작성한 전환 검토 항목이다. 교육 설계·승인 상태·PPTX를 변경하는 지시가 아니다. 단계와 승인 순서는 `../../../guides/governance.md`를 따른다.

| 공통 제작 | 현재 Markdown 표식과 자동 게이트는 일부 세션·레이아웃을 대상으로 동작한다. 현재 다음 세션 검사는 `course-design.md`의 세션 목록을 읽고, 원고 작성 훅은 이전 구성안 절차를 안내한다. | 세션 목록의 소유권을 이관할 때 기존 검사의 입력 계약과 전환 순서를 함께 결정한다. 승인 DD–Deck 대조, 노트·메타데이터의 출력 분리, 실제 응답·도식·코드·표의 정합성을 검증한다. 지원되지 않는 검사는 요구사항과 수동 확인 방법을 함께 기록한다. |

먼저 기존 승인 기준선과 적용 범위를 확인한다. 이후 Course Design과 Curriculum의 소유권·시간·인계를 승인하고, 순서대로 DD를 검토·통합한다. 대상 Deck이나 PPTX의 승인 상태는 기존 근거로 확인한다. 기존 기록만으로 확인할 수 없는 사항은 전환 검토에 남긴다.

## 구현 대기

1. Curriculum의 세션 목록·순서·시간·후속 연결을 기존 과정 목차와 참조 검사에 연결한다. 과정명·과정 목표·영한 용어집은 Course Design에서 유지한다.
2. DD를 Deck용 CLI·원고 훅의 검사 대상에서 구분한다. 승인 DD–Deck 버전 연결, 학습자·노트·제작 메타데이터의 분리 및 좌우 실습 게이트를 함께 검증한다.
3. S03의 실제 응답 전문 등록 및 S05의 옛 08절 제작 지시를 해당 승인 기록으로 재확인한다. 기존 시험·실행·제작 기록은 이관 증거로 보존한다.
