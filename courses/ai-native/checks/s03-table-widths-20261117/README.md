## 계산과 구현

맑은 고딕 실제 일반·굵은 글꼴, 각 셀의 현재8/10pt와 좌우 여백을 사용했다. 표 템플릿의 커닝 임계값12pt를 반영해8/10pt에서는 커닝을 끈 글자 전진폭을 사용한다. 초안에서 PENDING_PAYMENT 끝 글자가 끊기는 것을 발견해 이 계측 차이를 바로잡았다. 머리글과 숫자·단위·상태 토큰을 유지할 최소 폭을 확보하고 실제 행 높이·줄 수를 개선하는 배분만 선택한다. 이미 모두 한 줄인 표 및 유의미한 개선이 없는 표는 변경하지 않는다.

같은 머리글·전체 폭으로 이어지는 표는 모든 행을 함께 계측해 동일한 열 벡터를 사용한다. 현재 S03의 표는 장간 분할되지 않지만, 여러 장의 행을 함께 고려하는 회귀 fixture로 검증했다. 산정한 행 높이의 합을 frame cy에 반영한다. 표 뒤 실제 본문만 새 높이에 맞춰 이동하며 쪽수·빈 템플릿 개체는 이동하지 않는다. 최종 검사에서28쪽 쪽수가 이동하는 결함을 발견해 수정하고 회귀 테스트·재생성·28쪽 재렌더를 수행했다.

변경 파일: `engine/production/src/builder.js`, `tableRowMetrics.js`, 신규 `tableColumnMetrics.js`·`test/table-column-metrics.test.js`, 정식 PPTX·QA와 이 검증 디렉터리. 최신 제작 지침에는 이미 이번 열 너비 기준이 명시돼 있어 지침 내용을 다시 바꾸지 않았다.
