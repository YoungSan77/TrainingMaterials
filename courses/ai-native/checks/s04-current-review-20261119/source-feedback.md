# S04 원고 검토 피드백

대상: `courses/ai-native/sessions/s04.md`. 이번 작업은 검토본 제작이며 원고를 수정하지 않았다. 아래 판단은 Production의 자동 검사나 콘텐츠 승인으로 대체하지 않는다.

1. **725행, 13절 코드·테스트 대응 표 — 실행 범위 구분 필요.** “결제 거절 후 재결제에서도 주문 번호가 같은지 확인한다.”는 현재 `StaticModelTest.java`의 실제 실행 범위에 없다. 테스트는 상품 식별자·배송지·생성 상태와 금액/항목/값 제약 등을 확인하며 결제 거절·재결제를 실행하지 않는다. 13절 강사 노트도 결제·배송은 확인하지 않았다고 명시한다. 표의 이 항목을 향후 행동 검사의 기준으로 읽게 할지, 현재 코드에서 확인한 항목과 나누어 설명할지 작성자 판단이 필요하다. 이 문장을 실제로 통과한 Java 검사로 판정하지 않았다.
2. **357행과 947행, 강의 모델과 실제 응답 모델의 관계 표기 차이 — 설명 연결 확인.** 강의는 주문·항목을 합성으로, 실제 실행 응답은 일반 연관으로 표현한다. 기존 실행 README가 이미 구분한 차이이며 이번에 생긴 변조가 아니다. 별첨은 실행 원문과 일치하므로 원문을 합성으로 바꾸지 않았다. 같은 다중성을 다른 관계 표기로 표현한 차이를 강의에서 명확히 설명할지 확인할 수 있다.
3. **자동 원고 경고 24개 유지.** 일반 표 한 줄 초과 9개, 강조 없음 11개, 실제 응답의 묶음 구조 1개, 강사 노트 누락 2개, 한글 숫자 표기 1개다. 강사 노트 누락 위치는 「09. 주문 모델의 속성과 관계」(499행), 「요구사항으로 모델 판정하기」(542행)다. 숫자 표기는 「관계 표기 읽기」의 도식 제목 ‘네 가지 관계 표기’(255행)다. 강조·문장·노트 보완은 저자 판단으로 남겼다. 경고 전문은 최종 QA의 `warnings`에 보존했다.

일반 표의 실제 렌더는 줄바꿈을 수용하며 전체 421셀의 원문·경계 대조를 통과했다. 표 줄바꿈 원고 경고를 삭제하거나 개별 예외로 무시하지 않았다. 실제 응답의 목록 구조 경고도 원문 일치와 별도로 유지했다. SA 완료는 경고 0개 기준에 미달하며, Human의 콘텐츠 승인 여부를 새로 판단하지 않았다.
