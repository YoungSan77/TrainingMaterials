# S03 일반 본문 표 자연 폭 검증

최신 제작 지침의 「S03 일반 본문 표의 열 너비」를 적용했다. 일반 본문11표의 네 방향 여백은 모두5400EMU다. 각 열의 머리글·본문에서 실제 맑은 고딕 크기와 굵기로 가장 긴 명시적 줄을 계측하고 좌우 여백을 합했다. PowerPoint 표시와 원본 글꼴 전진폭 사이 차이를 고려해10pt 전진폭은0.25pt 표시 단위로 올림해 보수적으로 산정했다. 처음 렌더에서 일부 끝 글자가 줄바꿈돼 이 차이를 보완했고, 보완 후 모든 셀이 한 줄로 표시됨을 최종 PDF에서 확인했다. 이 반올림은 글꼴 폭의 표시 경계이며 이전 전체 표 폭을 채우는 분배는 없다.

열 너비의 합을 frame cx로 직접 지정했다. 기존 표 중심 정렬을 유지했고, 행 높이·frame cy·후속 내용 배치를 새 여백에서 다시 계산했다. 일반 표의 최소0.8cm 행 높이는 유지한다. 시연·판단표·별첨은 전용 경로 그대로이며 해당 장과 나머지 범위 밖 장은 생성 전 슬라이드XML과 동일하다.

표 전체 폭의 전후 값은 같은 이름의JSON에 저장했다. 검사 스크립트가 모든 일반 본문 셀의 네 방향5400과 frame cx=열 폭 합, 최종PDF의 모든 행 문구와 한 줄 표시를 확인했다. 변경11장(3·6~9·12~15·21·23)만 렌더링해 최장 셀 잘림·불필요한 줄바꿈·뒤 설명 겹침이 없음을 확인했다. PDF는 `out/review/s03/s03.pdf`, 좌표는 `out/s03-natural-bbox.html`이다.
