# AI-native SW 공학 — Curriculum / Session Architecture

세션의 ID·제목·순서·시간·역할·선수 관계와 산출물 인계의 승인 정본이다. [Course Design](course-design.md)의 승인 범위와 O01~O12를 적용한다. 이 문서의 승인은 Session Architecture에 해당하며, DD별 승인과 전체 Curriculum의 통합 검토는 후속 단계다. [Human 승인 및 기준선 기록](checks/ai-native-transition.md#2026-11-25-정본-전환과-승인)

## 과정 개요

주문한다 사례를 사용해 무엇을 맡길지 고르고, 요구사항·정적/동적 관점·아키텍처·설계를 결정한 뒤, 계약과 권한을 갖춰 업무를 맡긴다. 검사로 완료를 판정하고, 비용과 평가로 위임을 다시 판단한 뒤, 대표 작업 단위와 정책 보완으로 종합한다. S01은 과정의 지도를 제공한다. S01~S07은 결정과 초안, S08~S12는 실행과 증거를 중심으로 둔다. 순서는 학습 편성이다. 뒤 활동에서 발견한 근거는 앞 결정으로 환류한다.

네 요소의 기존 분담을 유지한다. 명세·모델·맥락은 S03~S07, LLM과 에이전트는 S02·S08, 권한과 변경 통제는 S09, 실행 가능한 검사는 S10이 담당한다. S11은 위임을 지속할지 평가하고 S12는 전체 흐름을 종합한다.

## 세션 구성과 시간

시간 단위는 분이다. **‘교육 14시간’은 편성 경과시간 840분**이며 교육 활동 700분과 휴식 140분을 포함한다. 교육 활동은 강의·결과 비교 480분과 실습 220분이다. 강의 열에는 결과 비교를 포함한다. 별도 토론 시간이나 점심 등 별도 운영 시간을 추가할 근거는 확인되지 않았다. 휴식 열은 편성 60분당 10분이라는 기존 산정 규칙의 세션별 환산치다. 실제 휴식 위치는 별도 운영 결정이다. O01~O12는 Course Design의 승인 성과 ID다.

## 세션 간 경계와 원전 인계

- S03은 범위·제외·미정 및 수용 기준을 정한다. S04는 개념과 관계, S05는 사건과 전이로 구체화한다. 두 모델 관점은 서로를 검증하며 정적 모델과 동적 모델을 별개 업무 모델로 분리하지 않는다.
- S05는 상태 기계와 시퀀스 다이어그램을 학습·실습의 중심으로 삼는다. 커뮤니케이션·액티비티·DFD는 같은 주문 사례에서 용도와 차이를 비교 소개한다. 표기법 작성 숙련은 범위 밖이다. O05의 실습 검토 기준은 DD에서 구체화한다.
- S06은 패키지 경계, S07은 객체 책임과 협력을 가르친다. 같은 원칙을 다른 결정에 적용한다. S09의 사전 차단과 S10의 사후 탐지, S02의 비용 구조와 S11의 비용·효과 판단도 각각 역할을 구분한다.
- 기존 기준 원전 활용 위치를 이어받는다. 위임 형태 [Anthropic 2024]는 S02·S08·S09, 맥락 [Anthropic 2025c]는 S02·S08, 명세 [Böckeler 2025]는 S03, 검사 [Böckeler 2026a]는 S10, 평가 [Anthropic 2026a]는 S11, 위험 [NIST 2023]은 S09·S11, 아키텍처 [Martin 2000]은 S06·S07에 연결한다. 보완 자료 활용 위치와 용어의 정의 세션은 [전환 직전 설계](checks/course-design-before-split-20261125.md)의 「기준 원전과 참고 자료」 및 주제별 용어표에서 읽어 해당 DD 검토 시 이관한다. 공통 정의·판본·적용 결정은 [Course Design](course-design.md)에서 소유한다.

## Session DD 인계

세션 DD의 예고 경로는 `sessions/sNN-detailed-design.md`다. 승인 편성을 사용하고, [전환 직전 설계](checks/course-design-before-split-20261125.md) §5~6의 기존 세션별 거버닝 메시지·교수 흐름·실습 설계와 현행 증거의 범위를 확인한다. 승인 전환과 기존 원고 사이의 차이는 [전환 기록](checks/ai-native-transition.md#2026-11-25-정본-전환과-승인)에 연결한다. 개별 DD 승인과 Curriculum 통합 승인에서 교육 활동의 시간 적합성과 인계 범위를 검토한다.
