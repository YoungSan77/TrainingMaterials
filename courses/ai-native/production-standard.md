| 응답 안의 도식 | 채택된 도식은 원문 제목과 함께 표시한다. 두 도식이 모두 필요하고 최소 표시 크기를 지킬 수 있으면 한 장에 좌우로 배치한다. 분량이 많거나 제목이 없는 도식의 발췌 여부는 작성 단계에서 정한다. |

- **S03 8pt 표 행 높이** — 위 시연 응답·판단표·별첨 실습 답변 표는 일반 표의 고정 행 높이 대신 현재 열 너비와 좌우 셀 여백에서 맑은 고딕 8pt가 실제 줄바꿈되는 높이를 잰다. 행에서 가장 높은 셀의 텍스트 높이·문단 앞뒤 간격과 위아래 여백 각 0.15cm를 합한다. 표 개체 높이는 산정한 행 높이의 합이며, 뒤따르는 같은 단의 설명 배치도 이 높이를 사용한다. 사방 여백을 적용한 뒤 실제 줄바꿈에 맞춰 행 높이를 다시 계산한다. 기존 열 너비를 우선 사용하고, 잘림이나 불필요한 줄바꿈이 생기는 표만 필요한 폭을 조정한다. 원고·표 내용·글꼴·범위 밖 슬라이드는 보존한다(`tableRowMetrics.js`).
  - PowerPoint 기본 표 문단처럼 한글도 공백으로 구분된 어절을 우선 유지하며, 한 줄보다 긴 어절만 글자 단위로 나눈다. 글자 단위의 낙관적 계측으로 실제 3줄을 2줄 높이로 잡지 않는다.
- **S03 실제 응답의 출처 확인** — 기존 `production-2026-11-16/README.md`가 가리키는 실행 입력·후속 대화·응답 전문과 원고·PPTX를 대조한다. Codex가 사용한 입력과 그 실행의 응답을 확인해 기록한다. 저장된 실행이 기준 입력과 일치하면 그 실행을 사용한다. 불일치하거나 전문이 없을 때에만 해당 실행부터 다시 수행한다.
- **응답 표시와 첫 문단** — 시연과 실습 답은 첫 제목·첫 절부터 시작한다. 시연 도입 첫 문단은 글머리표와 들여쓰기 없이 첫 절 제목과 정렬한다. 그 밖에 소속 목록을 소개하는 무글머리표 문단은 조정본의 해당 목록 시작점에 맞춘다. 발췌 문구·절 번호·순서·생략 위치는 실행 전문과 대조한다. 시연 판단표는 같은 응답의 규칙과 질문에 대응시킨다.
- **검증 범위** — 이번 조정은 승인한 S03 원고와 수동 조정본 `s03_or.pptx`의 수정 사항을 적용한다. 요청과 관련 없는 문구·배치·글꼴은 현재 덱과 대조한다. 앞서 승인한 시연·실습의 좌우형 편집 구조와 응답 서식은 유지한다.

S03은 **전 장 렌더링**으로 통합 장 수·읽기 순서·잘림·겹침을 확인한다. OOXML로 유효 글꼴과 1줄 간격, 무글머리표 문단의 목록 기호 기준 X와 코드·시연 입력의 목록 본문 기준 X, 스토리 문형·예시의 14pt, Gherkin·시연 입력 전 줄의 12pt·전후 3pt, 좌우 열별 편집 개체 수와 편집 가능한 표를 확인한다. 표나 도식이 거버닝 메시지와 떨어지면 실제 사용 공간과 줄바꿈·문단 높이를 대조한다. 지정 배치로 담기 어려운 경우 해당 장·블록·원인을 기록한다.

- **외부 문장과 예문** — 저자 설명과 구별해 제시하는 주문 요청 및 품질 요구사항 예문은 큰따옴표를 한 쌍만 표시한다. 03 「요구와 요구사항」은 요구 예시와 요구사항 목록 사이에 간격을 두고, 목록 앞에 독립된 ‘요구사항’ 제목을 표시한다. 실행 기록과 코드 블록에는 표시용 따옴표를 추가하지 않는다.
- **S03 표 공통 셀 여백** — 일반 본문·시연 응답·판단표·별첨 실습 답변의 모든 표에서 머리글과 본문 셀의 좌·우·상·하 안쪽 여백을 각각 **0.15cm**(`marL=54000`, `marR=54000`, `marT=54000`, `marB=54000`)로 지정한다. 문단 들여쓰기와 셀 여백을 구분한다. 최종 PPTX에서 머리글과 본문 셀의 사방 값을 전수 확인한다.
- **S03 일반 본문 표의 열 너비** — 머리글과 본문을 포함해 열마다 실제 글꼴·크기·굵기로 셀 텍스트의 한 줄 표시 폭을 재고, 가장 긴 셀의 텍스트 폭에 좌우 여백을 합해 열 너비를 정한다. 명시적으로 줄을 나눈 셀은 각 줄의 폭 중 가장 긴 값을 쓴다. 표 전체 폭은 계산한 열 너비의 합으로 줄인다. 이전 표 전체 폭에 맞추기 위해 남는 폭을 가운데 열이나 마지막 열에 더하지 않는다. 이어지는 같은 표는 모든 장의 행을 함께 고려해 같은 열 너비를 사용한다. 열 너비 합이 배치 가능 폭을 넘는 표만 필요한 줄바꿈을 허용하고 렌더링에서 확인한다.
- **너비 변경 후 배치와 확인** — 열 너비 합을 실제 표 개체 폭에 반영하고, 새 폭과 여백에서 필요한 행 높이·표 높이·뒤 설명의 위치를 다시 계산한다. 기존 글자 크기·편집 가능한 표·표 정렬을 유지한다. 가장 긴 셀이 잘리지 않고, 불필요한 오른쪽 빈 공간이 줄었는지 확인한다. 일반 본문 표에는 위의 내용 기반 열 너비 규칙을 적용한다. 시연 응답·판단표·별첨 실습 답변은 공통 셀 여백과 8pt 표의 배치 기준을 함께 적용한다.
- **수정 장 확인** — 제목 아래 내용, 표, 뒤 설명의 순서를 확인한다. 렌더 화면에서 글씨 잘림과 겹침을 검토하고, 응답 표는 한 줄짜리 행과 여러 줄 행의 높이가 실제 내용에 맞는지 확인한다. 원고 검토 메모를 슬라이드에 출력하지 않는다.

## 실행 기록과 기준본 승인 조건

### 기록의 페이지 연결

- 시연의 `US-01`은 제목·설명·인수 조건이 한 열에 들어가면 한 묶음으로 계획한다. 현재 열이 부족하면 다음 열·장으로 묶음 전체를 옮긴다. 빈 열에도 들어가지 않을 때는 원문을 바꾸거나 줄이지 않고 기존 순차 분할을 유지한다.
- 그 직전 시연의 ‘용어 / 정의’ 표도 실제 8pt 높이로 계획해 US-01 묶음을 넣을 공간을 판단한다.
- 별첨의 ‘용어 / 표기 / 정의’ 표는 실제 8pt·사방 54000EMU·현재 열 너비의 행 높이로 배치 가능 높이를 계산한다. 뒤의 판매가·주문 생성 시점 단가 구분 문장은 순서를 유지해 표 바로 아래에 둔다. 기본 10pt 표의 추정 높이로 불필요하게 다음 장으로 넘기지 않는다.
- 뒤의 ‘9. 미정 사항’은 가능한 경우 제목·본문·목록·생략 표시를 함께 다음 열·장으로 넘겨 생략 표시만 마지막 장에 남지 않게 한다.

### 승인 증거

- 원문 보존7건의 대상과 실행 기록은 `recorded-checks.json`에 둔다. 실습 첫/최종 프롬프트2개는 일치할 때 `unboldedText`만, 시연 US-01~04의 ‘인수 조건:’와 별첨 대표 상황의 ‘공통 사례는 다음과 같다.’5개는 일치할 때 `flatGroupItems`만 제외한다. 대조 결과와 해시·근거를 해당 제작 검증 기록에 남긴다. 다른 저자 문장과 구조·렌더 검사는 계속 적용한다.

- 실행 원본: `sessions/code/s03/exercise-conversation/production-2026-11-16/`. 검증 기록은 `checks/`에 둔다. 입력·첨부·응답 전문·이벤트의 일치를 확인한 실행만 재사용한다.
- 승인된 원고와 동일 입력 버전의 PPTX·QA를 생성하고 SHA256을 함께 기록한다. 최종 전 장 렌더링, 모든 표 셀 사방 54000EMU, 일반 표 내용 기반 열 너비·전체 폭, 시연·판단표·별첨 8pt를 검사한다.
- 원고 정합성·자동 검사·최종 렌더 검증을 각각 판정한다. 미해결 오류·경고·필수 미확인을 기록하며, 검증 완료 전 다른 세션 제작을 시작하지 않는다. 자동 통과와 Human의 기준본 승인을 구분한다.
- 참조 PPTX는 배치 참고이며 원고 의미의 원천이 아니다. 위의 `s03-op.pptx`와 `s03_or.pptx`는 서로 다른 이름이므로 대체하지 않는다. 접근 가능한 파일이 없으면 대조를 NOT VERIFIED로 남기고 현재 원고·명시된 수치 기준으로 검증한다. 보호된 참조 폴더는 사용하지 않는다.
