# AI-native 과정별 제작 기준

공통 서식·표 계측·인용·실습 배치·실제 응답 보존과 분할·검증은 `../../guides/production-guide.md`의 「표의 행 높이와 열 너비」·「인용문」·「문서 형식」·「목록 본문 정렬」·「소스 코드」·「최종 Production 검증과 증거」를 따른다. 이 문서는 AI-native의 적용 차이와 승인 기준본에 남은 세션 예외만 정의한다. 다른 세션·과정에 예외를 복제하지 않는다.

## 공통 기준과의 차이

- 과정 전체에 별도 수치 예외는 없다. 실행 원본의 위치와 검토 기록은 각 세션의 강사 노트와 `checks/`에서 찾는다.
- 아래의 S03 예외는 승인 커밋 `038cb6ffb291d741e643425ea19bf75f0ccf2c75`의 읽기 순서와 가독성을 보존하기 위한 것이다. 콘텐츠 역할 규칙을 세션 번호로 대신 판정하지 않는다.
- S03 일반 본문의 문단 앞뒤 간격은 각 3pt로 유지한다. 다른 세션은 공통 기본값을 쓴다.
- S03의 요약형 인용도 번역문을 표시용 큰따옴표로 감싼 승인 서식을 유지한다. 첫 문단 뒤에 놓인 표식 인용은 승인본처럼 목록 소속 크기를 유지한다. 공통 기준의 요약형 인용은 요약을 직접 인용으로 바꾸지 않으며, 독립 표식 인용과 원래 bullet 인용을 구분한다.
- 아래 표의 특정 장 통합·문형·명칭은 내용별 배치 결정이다. 표 셀의 공통 수치나 원문 보존 규칙을 다시 정의하지 않는다.

## S04 적용 차이

- 2026-11-18 제작 지시에 따라 영문 원문이 있는 인용은 한글 번역문과 영문을 각각 `“ ”`로 감싼다. 요약형 한글에도 적용하는 표시 서식이며 원문 내용이나 직접 인용 여부를 바꾸지 않는다. 공통 인용의 글머리표 제거와 역할별 크기는 그대로 따른다.
- S04 별첨은 원고 강사 노트에 따라 공통 「문서 형식」의 단내 표·왼쪽 우선 흐름을 선택한다. 표의 내용 기반 폭 계측·분할·원문 보존은 공통 기준을 참조하며 여기서 재정의하지 않는다.
- 적용 조건은 AI-native의 `04. 도메인 모델 — 정적 관점` 별첨 실제 응답이다. 강의 본문의 일반 표나 S03 승인 배치에는 단내 표 제한을 적용하지 않는다. 근거는 현재 `sessions/s04.md` 별첨 강사 노트와 위 제작 지시다.
- `s04-final_fb.pptx`의 장별 지시에 따라 「연관명과 다중성」은 문단 앞뒤 3pt·자료 사이 4pt로 한 장에 둔다. 본문·인용·표 글자 크기를 줄이지 않는다. 10절 번호 질문의 끝 문장부호가 단독 줄로 넘어가는 경계는 오른쪽 내부 여백에서 1.5pt를 회수한 S04 배치 예외로 유지한다. 근거와 실제 출력은 `checks/s04-feedback-20261118/README.md`에 있다.

## S05 적용 차이

- S05의 08절은 실제 첫 응답의 상태 기계·시퀀스 발췌 도식을 왼쪽, 문제·근거·수정 결과를 오른쪽에 놓는다. 별첨은 전체 응답을 실행 기록에 보존하고 목록·표의 대표 2항목 또는 2행과 생략 표식 `.....`을 사용한다. 텍스트·표·도식은 원문 순서대로 좌우 단에 배치한다. 모든 표는 한 단 안에 두고 필요하면 행을 나누고 머리글을 반복한다. 도식은 전이·메시지·순서를 보존하며 설명용 주석을 덜어내어 한 단의 7pt 표시 하한을 충족하는지 검사한다.
- 별첨 표는 공통 8pt를 유지하고 좌우 셀 내부 여백에 3pt를 적용한다. 7열 이상은 좌우 여백 2pt로 표시한다. 위아래 여백은 공통 기준을 적용한다.

## S03 전용 제작 기준

정식 원고는 `courses/ai-native/sessions/s03.md`다. 수동 배치 조정본 `references/inputs/s03-op.pptx`와 `s03_or.pptx`는 각각 지정된 대조에 사용한다. 두 파일은 이름과 역할을 확인하며 보호된 참조 폴더는 사용하지 않는다.

| 항목 | S03에서 확인할 결정 |
|---|---|
| 통합 장 | **02** 첫 장은 최초 요청·질문·확정 규칙 표, 둘째 장은 반례 도식. **05** 첫 장은 표현 방법 비교표·한영 문형·주문 예시, 둘째 장은 카드·대화·확인·INVEST와 고객 가치 문장. **07**은 흐름과 범위·제외·미정을 한 장에 둔다. **08·09·13**은 설명과 예·표·도식을 주제마다 한 장에 둔다. |
| 사용자 스토리 문형 | 영문·한국어 문형과 주문 예시는 14pt, 한국어 문형은 Bold다. Jeffries 인용문은 카드·대화·확인 목록 앞에 둔다. |
| 「03. 요구와 요구사항」 | 요구 예시와 요구사항 목록 사이에 간격을 두고 목록 앞에 독립된 ‘요구사항’ 제목을 둔다. |
| 실습 문제 | 실제 PowerPoint 목록으로 출력할 프롬프트는 두 문단이다. |

- S03 실행 원본은 `sessions/code/s03/exercise-conversation/production-2026-11-16/`과 그 `README.md`가 가리키는 입력·후속 대화·응답 전문이다.
- S03의 원문 보존 7건은 `recorded-checks.json`을 따른다. 실행본과 일치하는 실습 첫·최종 프롬프트 2개는 `unboldedText`만, 시연 `US-01`~`US-04`의 ‘인수 조건:’과 별첨 ‘공통 사례는 다음과 같다.’ 5개는 `flatGroupItems`만 제외한다. 대조 결과와 해시·근거를 해당 제작 기록에 남긴다. 그 밖의 저자 문장과 구조·렌더 검사는 계속 적용한다.
- S03은 승인 원고와 수동 조정본의 통합 장 수, 시연·실습의 좌우 편집 구조, 스토리 문형·예시의 14pt, S03 전용 배치를 전 장에서 확인한다. 승인본에서 적용된 예외는 해당 블록에 한한다. 기존 S03 검증 기록과 기준본 승인 상태를 보존한다. 다음 세션 제작의 선행 조건으로 둔 S03 검증 완료 여부는 이 기록으로 확인한다.
