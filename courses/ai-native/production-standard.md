# AI-native 과정별 제작 기준

제작의 공통 기준은 `../../guides/production-guide.md`가 모두 정한다. 이 문서는 **그 공통 기준과 다르게 적용하는 것만** 적는다. 다를 것이 없으면 비어 있는 것이 정상이다.

## 공통 기준과의 차이

현재 없다.

## 이 문서가 비어 있는 이유 (2026-11-27)

2026-11-26에 과정 설계와 Curriculum을 다시 세우면서 세션 편성이 바뀌었다(`checks/STATUS.md`). 이 문서에 적혀 있던 기준은 모두 **그전 편성의 세션 셋**(요구사항·정적 모델·동적 모델이 각각 S03·S04·S05였던 때)에 대한 예외였고, 그 원고는 현재 승인 정본이 아니다. 근거가 사라진 예외를 남겨 두면 **번호가 하나 밀린 다른 세션에 엉뚱하게 적용된다** — 실제로 renderer가 세션명으로 그 예외를 켜고 있어서, 새 S03을 쓰면 옛 S04의 조판이 걸릴 상태였다. 그래서 문서의 예외와 renderer의 분기를 함께 지웠다.

지운 것은 다음이다. 되살릴 근거(그 배치를 요구하는 원고와 그 승인)가 생기면 **그때 다시 쓴다.**

| 지운 예외 | 무엇이었나 |
|---|---|
| 문단 간격 3pt | 특정 세션의 일반 본문만 앞뒤 3pt로 좁혔다. 공통 기본값은 6pt다. |
| 요약형 인용의 표시 따옴표 | 특정 세션에서 한글 요약까지 큰따옴표로 감쌌다. 공통 기준은 요약형 한글에 따옴표를 두지 않는다. |
| 번호 내어쓰기 14.4pt·오른쪽 여백 회수 | 특정 장의 번호 목록과 질문 끝 문장부호를 맞추려던 값이다. |
| 코드 블록의 목록 들여쓰기 | 특정 세션에서만 코드 단을 목록 본문에 맞췄다. 지금은 공통 규칙이 모든 세션에 같게 적용된다. |
| 별첨의 단내 표 | 특정 세션의 기록 별첨만 표를 단 안에 두었다. 지금은 원고가 `**문서 형식 — 단내 표**`로 요청한다. |
| 도식과 표를 한 장에 두는 범례 배치 | 특정 세션의 표 제목으로 켜졌다. 지금은 원고가 `**배치 — 도식과 표 한 장**`으로 요청하고 제목은 도식·표 자신의 표식에서 읽는다. |

## 예외를 다시 쓸 때

- **먼저 공통 기준을 고칠 수 있는지 본다.** 한 과정에만 맞는 것이 아니면 `production-guide.md`를 고치는 것이 맞다.
- **세션 번호나 세션명으로 적지 않는다.** 번호는 편성이 바뀌면 다른 세션을 가리킨다. 원고가 표식으로 요청하게 하고, 이 문서는 그 표식을 **언제 쓰는지**를 적는다.
- **renderer에 과정 이름이나 세션명을 적지 않는다.** Renderer는 어느 과정의 원고인지 모른 채 표식만 따른다(`guides/production-guide.md` 「과정별 제작 기준」).
- 근거(어느 원고의 어느 장이 왜 그 배치를 요구하는지)와 확인 결과를 `checks/`의 제작 기록에 남긴다.
