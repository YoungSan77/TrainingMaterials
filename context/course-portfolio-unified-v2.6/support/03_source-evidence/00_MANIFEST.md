## Standard Evidence Metadata

각 Source Evidence Pack은 provenance와 verification을 섞은 임의 status 대신 다음 속성을 분리해 사용한다. 세부 claim이 많을 경우 pack 상단의 Classification Matrix로 묶어도 된다.

- **Verification Status:** Verified / Traceable / Hold / Pending
- **Evidence Role:** Foundational/Core / Empirical / Standard-Reference / Established Practice-Pattern / Contextual Adaptation / Case-Example / Practitioner Heuristic / Vendor-Product Implementation
- **Source Provenance:** Original-Foundational Author / Standard-Official Specification / Research-Empirical Program / Authoritative Secondary / Organizational Primary / Vendor-Product Documentation / Commentary-Tertiary
- **Evidence Strength:** Strong / Moderate / Limited / Pending
- **Transferability:** Broad / Conditional / Local-Institutional / Product-specific
- **Curriculum Use:** Core / Supporting / Example-Heuristic / Reference / Hold
- **BP Classification:** Not classified (default) / Contextual-Korea BP / Korea WP (필요한 경우만)

`Primary/Official`은 provenance 또는 verification을 설명할 뿐 Evidence Strength를 자동 결정하지 않는다.

## Rules

- 공식/원출처를 우선한다.
- 시점 의존 정보는 검증일을 기록한다.
- 과정별 근거가 아직 불충분하면 해당 파일 안에서 GAP을 표시하고, 별도 임시 파일을 만들지 않는다.
- Course Baseline과 충돌하는 근거자료가 발견되면 Course/Governance를 수정 검토하되 Evidence 파일 자체를 Course authority로 승격하지 않는다.
