## Asset Admission Rule

새 자산은 다음 조건을 모두 만족할 때만 추가한다.

1. 특정 과정에서 반복 재사용된다.
2. Course Baseline에 넣기에는 상세하거나 강사용이다.
3. Governance 또는 Source Evidence와 역할이 중복되지 않는다.
4. 해당 과정 폴더의 기존 자산과 책임이 겹치지 않는다.
5. 임시 작업기록이나 일회성 migration 산출물이 아니다.

없는 자산을 미리 placeholder로 만들지 않는다.
