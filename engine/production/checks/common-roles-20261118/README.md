# 공통 제작 기준과 역할별 적용 검증 — 2026-11-18

범위는 공통 제작 계약과 기존 renderer·QA의 적용 경로다. 정식 교재 산출물을 재발행하거나 Human 승인을 대신하지 않는다. 브랜치는 `migration/portfolio-v2.6-absorb`이며 커밋·푸시는 하지 않았다.

## 공통으로 이동한 계약

단일 원천은 `guides/production-guide.md`의 「콘텐츠 역할별 제작 계약」이다. AI-native 문서에 있던 공통 규칙은 제거하고 이 절을 참조하게 했다.

| 항목 | 공통 계약과 적용 |
|---|---|
| 표 역할 | 일반 강의·일반 문서 10pt, 실제 응답·응답 판단표·실제 실습 답 8pt. 세션 번호로 판정하지 않는다. |
| 셀·열·행 | 전 셀 사방 0.15cm·세로 가운데, 실제 글꼴과 표시 폭·줄바꿈·문단 간격으로 높이 계산. 일반 표는 0.8cm 최소, 응답 표는 고정 최소 없음. frame 크기는 열·행 합과 일치. |
| 너비 | 일반 표는 내용 기반 자연 너비, 실제 응답은 현재 폭에서 필요한 조정. 10pt 표시 반올림의 경계 여유를 명시했다. |
| 인용 | 독립 표식 인용 18pt, 원래 bullet 인용은 목록 크기, 영문·출처 10pt. 표시용 따옴표 한 쌍과 내부 따옴표·강조 보존. 요약형 한글을 직접 인용으로 바꾸지 않는다. |
| 실습 | 역할 그룹이 있는 문제는 목적 전체 폭·과제 왼쪽·결과물 오른쪽 한 장. 같은 크기에서 열 너비를 먼저 계측한다. |
| 원문 | 실행 입력과 실제 프롬프트가 일치하는 기록 재사용, 첫 제목·첫 절부터 문구·강조·절 번호·표·도식 원본·순서 보존. 발췌는 원고가 정하며 빠진 위치에 생략 표시. 저자 설명은 원문 밖. |
| 분할 | 열별 편집 개체와 표·도식의 별도 개체, 읽기 묶음 유지, 혼합 문서 원문 순서, 긴 실제 입력의 12pt 분할, 짧은 계산 블록 이어 쌓기. |
| QA | 역할별 셀·문단 끝 글꼴, 전 셀 여백, frame 폭·높이 합, 실측 행 높이, 인용 크기·무글머리표를 다시 읽어 검사. 일반 저작·출처 검사와 실제 렌더 검증은 별개로 유지. |

`contentRoles.js`가 원문 표식·문서 구간·판단표 머리글을 판정한다. 일반 문서 표식만으로 실제 응답이라고 추정하지 않는다. `builder.js`·`paragraphs.js`가 같은 역할을 적용하고 `inspect.js`·`structure.js`가 생성 manifest와 실제 출력에서 확인한다. 이전 S04의 로컬 monkey patch나 오류 발행 gate 해제는 사용하지 않았다.

## 충돌과 남긴 예외

- 이전 공통 지침의 ‘모든 표 0.8cm’는 역할별 **최소 높이와 실측 높이**로 정리했다. 고정 높이를 실제 응답에 적용하지 않는다. 같은 수치를 AI-native 문서에 재정의하지 않았다.
- 이전 영문 원문 바깥따옴표 생략과 AI-native의 표시용 따옴표 규칙은 공통 인용 절로 통합했다. 요약형 한글의 비인용 성격은 Session Authoring 계약대로 보존했다. 독립 표식 인용을 lead 뒤라는 이유로 16pt로 내리던 경로를 수정했다.
- 일반 문서·저자 답안과 실제 실행 응답은 역할을 분리했다. 실제 응답은 공통 10pt/8pt이며 원문 표식 없는 기존 저자 답안의 14/12/11pt를 실제 응답으로 오인하지 않는다.
- 결과물 그룹이 없는 기존 실습 입력은 기존 배치 경로를 유지한다. OOAD의 기존 `(안)` 저자 답안도 입력 호환으로 유지한다. 이 조건은 특정 과정 번호를 검사하는 예외가 아니라 입력 구조 차이다.
- AI-native에는 승인 S03의 본문 문단 간격 3pt, 요약형 번역문의 표시용 따옴표, lead 뒤 인용의 목록 소속 크기, 스토리 문형 14pt·굵게, 특정 장 통합·‘요구사항’ 제목 간격·기준본 연결점만 남겼다. 적용 조건과 승인 커밋 `038cb6ffb291d741e643425ea19bf75f0ccf2c75`를 명시했다.
- S03의 기존 좌우형 문서 구성 경로는 승인 배치를 대조하는 용도로 유지한다. 공통 표 수치·역할 판정은 이 profile과 분리했다. 임의 세션명과 다른 과정 fixture에서도 같은 역할 규칙이 적용됨을 검사했다.
- 별도 과정별 제작 기준 파일은 AI-native 외에 발견되지 않았다. 기존 표식이 실제 원문인 세션은 AI-native의 세션 01~09에서 확인된다. 일반 표·인용의 공통 변경은 다른 과정에도 적용되며, OOAD 대표 세션으로 회귀를 확인했다. 모든 과정의 전 세션 제작 검증을 수행한 것은 아니다.

## 검증

- 전체 고정 fixture: **320개 PASS, 실패 0**. `tests.log`에 최종 출력이 있다. 잘못된 마지막 셀 여백·행 높이·인용 크기 변조를 QA가 거절하는 검사, 임의 과정·세션 역할 검사, 긴 입력의 원문 분할 검사 등을 포함한다.
- 기존 테스트의 계약 변경은 공통 규칙 변경에 맞췄다. 독립 인용의 18pt와 표시용 따옴표, 실제 응답의 공통 크기, 특정 profile 대신 실측 행 대응 metadata를 기대하도록 바꿨다. 내용·원문 보존 및 기존 저자 답안·실습 호환 검사는 유지한다.
- S03 임시 출력 **30장**, 승인본 **30장**, 표 **254셀**의 값·행 순서 일치. 묶음을 함께 이동하면서 18·19·26·27장의 내용 경계가 달라졌다. 같은 문구를 더하거나 삭제한 변화가 아니라 절·목록 묶음의 페이지 이동이다. 이 네 장을 승인 복사본과 대조했다. 승인본 파일은 바꾸지 않았다.
- S04 임시 출력 **49장**, 내용·역할 서식 검사 오류 **0**. 기존 실습 열 초과를 한 장 계측 배치로 해결했다. 긴 이전 입력은 원문·공백을 보존한 12pt 두 장이다. 독립 인용·응답/판단표 8pt·원문 도식 주석과 읽기 순서를 확인했다. 이전 로컬 검토본 55장을 정식 산출물로 덮어쓰지 않았다.
- OOAD `courses/ooad/sessions/s02.md`: 변경 전후 임시 출력 **93장**, 표시용 따옴표를 제외한 장별 텍스트와 전 표 값 일치. 일반 표 **715셀**에 공통 여백과 10pt를 적용하고 기존 실습·저자 답안의 구조를 유지했다.
- PDF 검사에서 빈 셀의 문단 끝 글꼴이 상속되어 실제 행이 커지는 문제가 확인됐다. 모든 셀의 문단 끝/기본 글꼴까지 역할 크기로 명시하고 QA에 연결했다. `pdf-verification.json`은 최종 같은 출력 버전의 PDF 텍스트·행 경계 대조 결과다.
- 최종 PDF에서 S03 254셀·S04 433셀·OOAD 715셀, 합계 **1,402셀의 텍스트 일치·행 경계 검사 모두 통과**했다. 발견했던 OOAD 21·61·65장의 불일치는 해소됐다.
- 최종 이미지 검토 대상: S03 8·18·19·26~30장(8장), 승인 복사본 18·19·26·27장(4장), S04 4·20~23·30·32~49장(24장), OOAD 6·9·11·21·61·65·87·90장(8장). 총 **44장**의 표·인용·실습·응답·도식을 검토 대상으로 삼았다. 전 장 최종 교재 승인 검토가 아니다.

## 남은 항목과 경계

S04의 기존 원고 참조 오류 **7개**는 그대로다. 621행 파일명식 참조, 792행 다른 세션의 잘못된 topic 참조, 실제 응답 안의 파일명식 표기 5건이다. 원고를 수정하거나 원문을 일반 문장으로 바꾸어 숨기지 않았다. 임시 `.qa.json`은 내용/서식 재읽기 검사와 읽기 전용 참조 검사의 범위를 구분하며 S04는 이 참조 오류로 FAIL이다. 모든 SA 경고를 검사한 정식 CLI 발행 결과로 설명하지 않는다.

S04 35장의 짧은 후속 문단 등 지면 밀도는 정식 세션 제작 때 추가 조정할 항목이다. 원고의 명시 구간과 원문은 유지했다. 이번 단계는 공통 적용 경로의 검증이며 S04 최종 제작 완료·Human 승인을 선언하지 않는다.
