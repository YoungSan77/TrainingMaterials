### Source Gate
- [ ] Global Principle / Global BP와 국내 관행이 충돌할 경우 Global 기준을 우선했다.
- [ ] Global principle을 한국 관행만으로 정당화하지 않았다.
- [ ] 국내 2차 자료는 가능한 경우 원출처를 추적했다.
- [ ] Korea BP/WP/Local Context를 명시적으로 구분했다.
- [ ] 법/규제 제약과 engineering BP를 혼동하지 않았다.
- [ ] 번역어가 원개념을 왜곡하지 않는지 확인했다.

## 15. Course Admission Check
- [ ] 독립 문제를 가진다.
- [ ] 새 OWNER 또는 충분히 큰 EXTEND 영역이 있다.
- [ ] 기존 과정 module로 충분하지 않다.
- [ ] 기존 OWNER 정의를 복제하지 않는다.
- [ ] Tool/Vendor가 사라져도 identity가 남는다.
- [ ] Trade-off / Failure Condition이 있다.
- [ ] 학습 evidence를 정의할 수 있다.
- [ ] 독립 수강자를 위한 Minimum Recap이 있다.
