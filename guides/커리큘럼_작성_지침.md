# 커리큘럼 작성 지침 (커리큘럼을 *어떻게* 쓰는가) > 버전: v1.0

> 이 문서는 커리큘럼(온톨로지)을 **저작하는 절차·구조 규칙**이다.
> **커리큘럼 세션에서만 첨부한다.** (덱 세션엔 커리큘럼 + 교재 작성 지침을 첨부하고, 이 문서는 넣지 않는다.)
> 형식 어휘(분류명·시각 타입·인용 형식·등급)의 **정본은 `교재_작성_지침.md`**다. 여기선 채우기용 토큰만 참조한다.
> 산출물인 커리큘럼에는 이 지침이 들어가지 않는다 — 순수 내용(무엇을 가르칠지)만이다.

---

## 참조 어휘 (정본: 교재 작성 지침)
채우기에 필요한 토큰만. 규칙·선택 기준은 교재 작성 지침을 본다.
- **분류:** 현상 / 원인 / 원칙 / 적용 / 타협
- **시각 타입:** flow · pipeline · loop · boxes · steps · versus · table · share · magnitude · pyramid · quadrant · statement
  (선택 힌트: 관계→flow류, 항목→boxes류, 숫자 명제→magnitude/share, 계층→pyramid, 두 축→quadrant. 상세는 지침 §3)
- **인용 등급:** PRIMARY / WIDELY-CITED · 블록 형식은 지침 §6

---

## A. 커리큘럼 문서 구조

### A0. 과정 개요
제목·부제·목적(수료 후 할 수 있어야 하는 것)·대상·총 시간·일수·세션 수·전개 축·철학.

### 용어 규칙 / 역할 매핑
그 교재가 고정하는 표준 용어·금지어, 직군–주체 매핑(있으면).

### A1. 개념 소유 매트릭스 — 반복을 유한하게 만드는 장치
개념마다 **원리 소유 세션 1개**. 재등장은 "심화·적용"으로만 표기, 원리를 다시 정의하지 않는다.
이 매트릭스가 세션 상세화의 범위를 고정 → 상세화가 발산하지 않고 종료된다.

### A2. 세션 노드 (세션마다 하나 — 온톨로지의 알맹이)
- no · 제목 · 학습목표(1줄)
- 문제 / 해결 / 적용 (각 요지) — 덱의 현상→(원인)→원칙→적용으로 전개됨
- 선택과 버림: 전제조건 · Trade-off · 실패조건 · 판단맥락 — 덱의 '타협' 분류
- 인용 ref: `[id, …]` — **인용은 골격이 아니라 근거다(v4.1)**: 명제와 직접 연결될 때만, 없으면 없음. 자산은 A3, 세션 태그는 권장 사용처(태그 밖은 경고).
- 시각 지정: 그림이어야 하는 명제 → 타입 (그것만 명시, 나머지는 덱 생성이 선택)
- 다음 연결

### A3. 인용 자산 — 커리큘럼 안 한 절에 모음 (분리 안 함)
별도 quotes.md를 만들지 않는다. 커리큘럼 문서 안 `## 인용 자산` 절에 **교재 작성 지침 §6 형식**으로 모아둔다.
verify가 이 절을 파싱해 세션 데이터의 인용을 원문과 대조한다. 세션 노드는 id로만 참조한다.

## B. 저작 프롬프트

### Stage 1 — 목차 확정
**첨부:** 이 문서(커리큘럼 작성 지침)
**요청:** "교재를 만든다. [총 시간·일수] / [도메인 요구사항: 주제·목적·대상·전개축·반드시 다뤄야 할 개념 목록]. **목차만** 먼저 뽑아라 — 일자별 세션 목록 + 개념 소유 매트릭스(A1) + 세션별 1줄 목표. 상세는 아직."
→ 사람이 목차·매트릭스 교정·확정.

### Stage 2 — 세션 상세화 (반복)
**첨부:** 이 문서 + 확정된 목차·매트릭스
**요청:** "세션 NN을 상세화하라 — A2 세션 노드 형식으로. 이 세션이 소유한 개념만. 인용은 A3 자산에서 명제와 직접 연결될 때만."
→ 세션 노드 하나 산출 → 사람 검토 → 다음 세션. 전 세션을 채우고 A3 인용 자산을 정리하면 커리큘럼 완성.

### 완결 판정
전 세션 노드 존재 · 개념 이중 소유 없음 · 참조 인용 id가 A3에 있음 · 자산 없는 세션은 빈 채로 정당.

## C. 이 다음 (덱 생성 — 다른 세션)
완성된 커리큘럼으로 덱을 만들 때는 **커리큘럼 + `교재_작성_지침.md`**를 첨부하고 "세션 NN을 덱 데이터로 생성"만 요청한다.
형식은 교재 작성 지침에, 내용은 커리큘럼 세션 노드에 이미 있으므로 요청은 최소다.
