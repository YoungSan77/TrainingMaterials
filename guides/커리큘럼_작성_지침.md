# 커리큘럼 작성 지침

> `portfolio/governance.md`가 통제하는 Curriculum stage annex다. Workflow, authority와 Session 01 공통 Guardrail은 Governance가 소유하며 여기서 반복 정의하지 않는다.

## Input

- 승인된 해당 과정 Course Design 전체
- Course Design이 요구하거나 허용한 Portfolio Common Standards
- Course Design에 포함되거나 연결된 검증된 Source와 실습 설계
- User Intent의 시간·운영 제약

기존 Curriculum, Deck, legacy session source와 다른 과정의 산출물은 생성 입력이나 보존 제약이 아니다.

## Responsibility

Curriculum LLM은 Course Design Guardrail 안에서 전체 교육과정을 완성한다.

- 확정 duration 안에서 Session 수, 제목, 시간과 학습 흐름을 설계한다.
- 각 Session의 outcome과 학습자가 이해·판단·적용해야 할 핵심 claim을 완성한다.
- 정의, 인과, 대조, 경계, 상태, 순서와 전환을 LLM이 추측하지 않아도 될 정도로 claim에 명확히 쓴다.
- 중요도·난이도·선수 관계·실습과 feedback 필요성에 따라 시간을 비균등하게 배분한다.
- 필요한 실습을 선택하고 준비·수행·feedback·산출물 시간을 교육 흐름에 배치한다.
- claim에 실제 필요한 검증된 Source와 Portfolio Common Standards만 Session에 routing한다.
- 상세 기법과 심화 적용은 충분한 개념·판단 기반 뒤에 배치한다.
- Governance가 소유하는 Session 01 공통 Guardrail을 적용하되 과정별 구조를 자율적으로 설계한다.

Guardrail은 최소 요구사항과 경계다. Curriculum LLM은 그 안에서 더 나은 설명, 근거, 사례, interaction과 구성을 자율적으로 보완할 책임이 있다.

## Output

Curriculum은 교육 orchestration의 단일 정본이며 최소한 다음을 소유한다.

- 과정 identity와 총 instructional time
- Session ID·제목·시간·outcome·학습 흐름
- Session별 핵심 claim과 필요한 관계·경계
- 선택한 실습과 배치
- 선택한 검증 Source
- 필요한 Portfolio Common Standards
- 다음 Session으로 이어지는 학습 전환

실습·Source·Common Standard의 상세 원문은 복사하지 않고 owner를 식별해 routing한다. 연결이 없으면 `없음`으로 명시할 수 있다. 특정 markdown field 이름이나 schema는 Harness가 실제로 요구할 때만 고정한다.

## Prohibited Behavior

- Course Design의 목적, target capability, scope, non-scope, ownership과 확정 시간을 변경하지 않는다.
- Course Design의 section이나 topic을 동일 시간 Session으로 기계 변환하지 않는다.
- claim 수, Session 수와 형식을 다른 과정에 맞추지 않는다.
- 기존 Curriculum·Deck·legacy source를 복원하거나 현재 정답으로 사용하지 않는다.
- 검증되지 않은 Source를 확정 사실이나 축자 인용 근거로 승격하지 않는다.
- Portfolio 전체를 무차별 routing하거나 실습·Source 수를 채우지 않는다.
- 실습 상세, Source 원문과 Portfolio 공통 규칙을 Curriculum에 중복 소유하지 않는다.
- storyboard, semantic IR, slide-plan과 session source를 중간 정본으로 만들지 않는다.

## Verification Expectations

### Deterministic

- Session time 합계와 총 instructional time이 일치한다.
- Session·claim·실습·Source·Common Standard 식별자와 연결에 누락·중복·dangling dependency가 없다.
- 필수 field와 형식이 Curriculum Harness 계약에 맞는다.

### Semantic

- Course Design의 필수 outcome과 ownership이 충분히 구현된다.
- 선수 관계, 난이도, 실습과 feedback을 고려한 학습 흐름이 자연스럽다.
- claim이 Deck LLM의 핵심 의미 추측을 요구하지 않는다.
- scope와 밀도가 시간 안에 실제로 가르칠 수 있다.

### Human

- Session별 교육 가치와 과정 전체 narrative가 승인됐다.
- 중요한 누락·중복·과밀과 boundary 오해가 없다.
- Deck stage의 Guardrail로 사용할 수 있다.
