# Curriculum / Session Architecture Guide

승인 순서·변경 통제·기준선 기록은 `governance.md`가 정한다. 이 지침은 **세션 사이**의 교육 설계를 소유한다. 세션 내부의 상세 설계와 원고는 `session-authoring-guide.md`가 소유한다. Markdown이나 Renderer의 기능을 교육 설계의 범위로 사용하지 않는다.

## Curriculum / Session Architecture

- **시작 확인** — Governance의 「단계 시작 계약」에 따라 이 지침, Course Design 승인 버전, 편성·시간·인계의 변경 허용 범위를 대조한다.
- **필수 입력** — 승인된 Course Design의 과정 목표·범위·시간 예산·공통 사례, 대상의 선수지식, 해당 과정에 지정된 검증 근거.
- **출력과 책임** — 과정 Overview와 Session Architecture를 `curriculum.md`에 작성한다. 세션별 ID·제목·역할, 순서, 강의·실습·토론 및 휴식을 구분한 시간, 선행 입력과 확정 산출물의 인계, 목표의 분담과 제외 범위, 세션 원고 경로를 기록한다. 세션 원고의 전체 주장·사례·프롬프트를 복제하지 않는다.
- **승인과 진입** — 먼저 Architecture에 대한 Human 승인을 받는다. 이후 승인된 세션 원고를 연결해 합계, 선수 관계, 중복·누락과 학습 흐름을 전체 통합 검토한다. 같은 예가 새로운 질문에 쓰이는 경우와 같은 판단을 반복하는 경우를 구분한다. 통합본의 Human 승인이 Production 진입의 조건이다.
- **필수 검사** — ID·경로의 유일성과 존재, 시간 합계, 선행 산출물의 선후 관계, 과정 교육 목표별 세션 연결을 대조한다(학습 성과를 정의한 과정은 그 성과별 연결도 함께 본다). 세션별 실습 시간의 합계가 편성과 맞는지 함께 본다. 전용 하네스는 미구현 요구이며 수동 대조 결과를 별도로 남긴다. 학습 전개의 타당성, 활동 시간의 현실성, 선행과 중복의 교육적 이유는 의미 검토한다.
- **실패·기준선** — 경계나 총시간 변경이 필요하면 Course Design에 환류한다. 세션 사이 시간·순서 수정은 Curriculum의 변경으로 기록하고 영향을 받는 세션 원고를 식별한다. 승인 Architecture, 통합본과 참조 원고 버전을 과정 기록에 연결한다.
