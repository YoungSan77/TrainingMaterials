# Course Design Guide

## 목적

Course Design은 과정 전체의 의미 구조와 세션 경계를 정의한다. 그 이상을 소유하지 않는다.

## 필수 항목

- 총 교육시간
- 대상 / 선수지식
- 과정 목표
- 목차 / 세부 목차
- 세션별 시간
- 세션별 목표
- Anchor Message (세션마다 한 개, 수강생이 가져가야 할 핵심 메시지)

## 좋은 Course Design의 판단 기준

- 세션 경계가 중복 없이 과정 목표 전체를 나눈다.
- 세션별 시간 합계가 총 교육시간과 정확히 일치한다.
- 각 세션 시간은 교육량과 실습 필요성에 따라 배분되어 있다(균등 배분이 아니다).
- 목차만으로 세션 간 순서와 경계를 알 수 있다.
- Anchor Message가 한 문장으로 그 세션의 핵심을 전달한다.

## 하지 말아야 할 것

- Session 상세 설명 작성
- slide 설계, visual 배치
- 코드 상세 작성
- renderer 제약 반영
- Curriculum/DD 생성

Course Design은 downstream Production의 형식이나 제약에 끌려가지 않는다. Production이 무엇을
할 수 있는지는 Course Design의 판단 기준이 아니다.
