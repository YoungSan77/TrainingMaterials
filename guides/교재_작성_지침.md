# 교재 작성 지침

> `portfolio/governance.md`가 통제하는 Deck stage annex다. Workflow와 authority는 Governance, executable schema·geometry·rendering behavior는 Engine이 소유한다.

## Input

- 이 지침
- 승인된 전체 Curriculum과 생성 대상 Session
- Curriculum이 해당 Session에 연결한 실습
- Curriculum이 해당 Session에 연결한 검증된 Source
- Curriculum이 해당 Session에 지정한 Portfolio Common Standards
- 현재 Engine의 executable contract

Course Design은 Curriculum의 누락을 우회하기 위한 직접 Deck 입력이 아니다. 기존 Deck, legacy session source와 연결되지 않은 자료도 입력으로 사용하지 않는다.

## Responsibility

Deck LLM은 Curriculum의 필수 교육 설계를 모두 계승해 해당 Session을 실제로 가르칠 수 있는 instructional/visual realization을 완성한다.

- Curriculum claim의 핵심 의미, 관계와 boundary를 learner-visible content로 구현한다.
- Session 시간에 맞는 설명, 예제, 질문, 짧은 interaction과 instructor notes를 보완한다.
- claim을 기계적으로 slide와 1:1 대응시키지 않고 자연스러운 논증 단위로 결합하거나 전개한다.
- Curriculum의 권장 slide 수와 허용 범위를 따르되, 필수 내용을 보존하면서 교육적·시각적 근거가 있으면 범위 안에서 가감한다. 범위를 벗어나야 하면 그 근거를 semantic/human review에 드러낸다.
- 인과, 전환, 경계, 책임, 상태, 순서와 대조가 내용이면 그 관계가 보이는 visual type을 선택한다.
- 과정 전체와 Session 내부에서 사례·용어·narrative를 일관되게 유지한다.
- Source의 검증 범위와 Portfolio Common Standard의 정의·규칙을 변경하지 않는다.
- Engine이 처리할 수 있는 유효 Deck data를 작성한다.

Harness는 Deck을 생성하거나 교육 내용을 대신 채우지 않는다. 오류는 수정해야 할 계약 위반이고, 경고는 semantic/human 판단이 필요한 신호다.

## Output

- Engine이 읽을 수 있는 해당 Session Deck source
- Curriculum claim과 slide realization의 추적 가능성
- 실제 강의 진행을 지원하는 instructor notes
- 필요한 Source attribution과 한계

PPTX, PDF와 PNG는 generated output이며 별도 승인된 regression baseline이 아니면 Git 정본으로 유지하지 않는다.

## Prohibited Behavior

- Curriculum의 교육 범위, claim, 순서, 실습 배치와 ownership을 바꾸지 않는다.
- Curriculum에 없는 핵심 주장이나 연결되지 않은 Source·Common Standard를 임의 추가하지 않는다.
- 기존 Deck의 문장·구성·layout을 정답으로 복사하지 않는다.
- 단순 카드·표·bullets를 관계 시각화의 대체물로 반복하지 않는다.
- claim 수를 slide 수와 1:1 대응시키거나 전 과정 공통 quota와 visual type 분포를 목표 수치에 맞추지 않는다.
- 인용을 의역해 축자 인용으로 제시하거나 Source보다 강한 사실을 만들지 않는다.
- Renderer 결함을 Deck 내용 왜곡으로 우회하거나 Deck 결함을 Engine 변경으로 숨기지 않는다.
- storyboard, semantic IR와 slide-plan을 persistent artifact로 만들지 않는다.

## Verification Expectations

### Deterministic

- `node engine/verify.js <deck>` 또는 동등한 현재 CLI 검사에서 오류가 없다.
- Curriculum claim coverage와 routing integrity가 완전하다.
- Curriculum의 필수 학습 목표·요약·실습 흐름과 slide 범위 계약이 추적된다.
- 알 수 없는 claim·Source·실습·Common Standard 참조가 없다.
- schema, 필수 field, quote exactness, geometry와 overflow 검사를 통과한다.

### Semantic

- claim의 의미·경계·사례가 축소되거나 왜곡되지 않는다.
- 시각 구조가 실제 인과·책임·상태·대조와 전환을 표현한다.
- 중복, 과밀, 과소 설명과 기계적인 layout 반복이 없다.
- Session 시간 동안 자연스럽게 설명하고 interaction할 수 있다.

### Human

- 실제 글자 표시, 가독성, hierarchy와 presentation 환경을 시각 검토한다.
- 교육적 전달력과 narrative를 승인한다.
- deterministic 통과를 최종 교재 품질 승인으로 간주하지 않는다.
