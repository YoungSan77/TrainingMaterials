- [ ] 국내 관행을 Global Baseline 관점에서 재검토했다.

- [ ] 국내 2차 자료는 가능한 경우 원출처를 추적했다.

- [ ] 법/규제/계약 제약과 일반 engineering principle/practice를 혼동하지 않았다.
- [ ] 번역어가 원개념을 왜곡하지 않는지 확인했다.
- [ ] Primary/Official 여부와 Evidence Strength를 분리했다.
- [ ] 특정 LLM/vendor/model/UI/API가 Course Concept·Practice·Artifact를 정의하지 않는다.
- [ ] 국제표준은 Course Decision의 직접 대상이 아닌 한 Reference 역할로 제한했다.

## 19. Time / Session Rule
- **Topic은 시간 단위가 아니라 학습 주제다.** 시간은 내용에서 파생한다.
- 모든 Topic을 50분으로 맞추지 않는다. 주제에 따라 20~30분, 40~60분, 60~90분 이상도 가능하다.
- 8h 과정은 총 운영시간 **480분 이내**, 16h 과정은 **960분 이내**로 설계한다.
- 50분 학습 + 10분 휴식은 운영 리듬일 뿐 Topic Boundary가 아니다. Topic은 운영 블록을 가로지를 수 있다.
- 50+10 운영을 적용할 경우 권장 순수 학습시간은 8h 약 **400분**, 16h 약 **800분**이며, Topic별 시간 합계는 이 범위에서 가변 배분한다.
- Session/Topic 수를 맞추기 위해 내용을 억지로 쪼개거나 합치지 않는다.

## 20. Awareness Topic Rule
핵심 Course Identity 밖이지만 실무 관심도가 높은 개념은 1~5분 수준으로 `정의 → 언제 필요한가 → 대표 위험`까지만 소개한다. 상세 사용법·자격시험·Tool tutorial로 확장하지 않는다.

## 21. LLM-Integrated Practice Gate
- [ ] Course duration에 맞는 Practice 수를 충족한다.
- [ ] Practice는 기존 instructional time 안에 포함된다.
- [ ] 실제 업무형 문제와 재사용 가능한 판단/산출물을 다룬다.
- [ ] Recommended Prompt를 시작 시 제공하지 않는다.
- [ ] 5–10분 후 판단을 강화하는 Intervention이 있다.
- [ ] Recommended Prompt는 종료 시 공개하며 정답이 아님을 명시한다.
- [ ] OWNER/RECAP/APPLY/FORWARD 경계를 바꾸지 않는다.
- [ ] 상세 교재를 불필요하게 삭제하지 않고 Optional/Reference/Appendix를 사용한다.
