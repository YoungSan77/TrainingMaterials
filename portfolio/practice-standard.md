# Portfolio 실습 Standard

이 문서는 여러 과정에서 공통으로 사용하는 실습의 최소 품질 계약을 소유한다. 교육 콘텐츠의 용어는 **실습**으로 통일한다.

## 1. Purpose

실습은 활동량이나 prompt 작성 능력을 평가하지 않는다. 학습자가 해당 과정이 소유한 판단을 실제 맥락에 적용하고, 결과를 검토·수정하며, 선택 이유를 evidence로 설명하게 한다.

## 2. Course Design Minimum

Course Design 수준의 각 핵심 실습 방향은 최소한 다음을 정의한다.

- 실습 목적
- 학습자가 내려야 할 판단
- 기대 산출물
- 실패 기준

시간, 세부 절차, 자료 공개 순서와 평가 rubric은 Curriculum이 전체 학습 흐름 안에서 완성한다.

## 3. LLM Use

LLM은 분석·대안·비판·검토를 가속하는 협력자다. 전문 판단의 owner가 아니다.

- 학습자가 문제와 첫 판단을 이해하기 전에 정답형 prompt를 제공하지 않는다.
- LLM 결과의 채택·수정·폐기 이유를 학습자가 설명한다.
- 중요한 가정과 claim은 source 또는 검증으로 확인한다.
- 다른 과정이 소유한 전문 결정을 LLM에게 위임하지 않는다.
- 특정 vendor/model/UI에 종속된 실습을 과정 spine으로 만들지 않는다.

## 4. Quality Gate

유효한 실습은 다음을 만족한다.

- Target Capability와 직접 연결된다.
- 실제 업무형 판단과 산출물이 있다.
- 한 가지 정답 대신 trade-off를 드러낸다.
- 실패 기준이 관찰 가능하다.
- 결과를 비판·수정하는 feedback loop가 있다.
- 실습 시간이 확정 교육시간 안에 포함된다.

실습 수와 시간을 Portfolio가 일률적으로 강제하지 않는다. Curriculum LLM이 중요도·난이도·feedback 필요성을 기준으로 배치한다.
